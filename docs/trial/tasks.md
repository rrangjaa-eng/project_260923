# 중간 사용자 시험: 할 일 목록과 기록표

> 시험을 돕는 사람(진행자)이 보는 문서입니다.
> 이용자에게는 [쉬운 사용 설명서](guide.md)를 드립니다.
> 근거: 설계 10장, 요구사항 TEST-01~03, 로드맵 2단계.

## 이 시험으로 알고 싶은 것

1. 도우미가 있을 때 **더 빠르고 덜 틀리는지** (TEST-01)
2. 기본값 세 가지가 이 분 손에 맞는지 (TEST-02)
   - 떨림 간격 300ms: 이 안에 같은 키·같은 자리를 또 누르면 무시
   - 잡는 범위 48px: 버튼에서 이만큼 떨어져도 잡음
   - 머무르기 시간 800ms: 이만큼 가만히 있으면 눌림
3. 다음에 무엇부터 만들지 (TEST-03)

| 확인 | 내용 |
|---|---|

| ☐ 시험 페이지 | 아래 "시험 페이지"대로 열고, 파일 URL 접근을 켰는지 봅니다. |
| ☐ 설치 | 웹스토어 비공개 링크는 2단계에서 만듭니다. 그 전에는 개발자가 만든 폴더를 크롬 `chrome://extensions` → 개발자 모드 → "압축해제된 확장 프로그램을 로드합니다"로 넣습니다. 회사 PC라면 확장 설치가 막혀 있지 않은지도 봅니다. |
| ☐ 브라우저 | 크롬으로 합니다. 엣지·웨일은 따로 확인합니다. |
| ☐ 장소와 시간 | 이용자 자기 PC, 평소 쓰는 마우스. 컨디션이 나쁜 날은 미룹니다. |
| ☐ 준비물 | 이 기록표, 필기구 (시간과 잘못 누름은 페이지가 셉니다) |

**회사 시스템에서는 시험하지 않습니다.** 회사 시스템이 완성된 뒤 따로 확인합니다.

## 시험 페이지

과제는 [trial.html](trial.html) 한 장으로 합니다. 설계가 정한 과제(작은 버튼 10개 누르기, 양식 하나 채우기)가 들어 있고, 걸린 시간과 잘못 누른 횟수를 페이지가 스스로 셉니다.

**여는 법**

1. `docs/trial/trial.html` 파일을 두 번 눌러 크롬으로 엽니다. 인터넷이 없어도 열립니다.
2. 파일로 연 페이지에서 도우미가 돌려면 한 번만 설정해 둡니다: `chrome://extensions` → 도우미의 "세부정보" → **"파일 URL에 대한 액세스 허용"** 켜기.
3. 페이지 왼쪽 아래에 "도우미" 표시가 보이면 준비된 것입니다.

**페이지가 하는 일**

| 부분 | 내용 |
|---|---|
| 방법 고르기 | 진행자가 "도우미 없이 / 자석 커서 / 번호표" 중 하나를 누릅니다. 고르지 않으면 과제가 시작되지 않습니다. |
| 과제 1 | 20px 버튼 20개 가운데 색이 칠해진 하나를 누르면 다음 버튼에 색이 옮겨 갑니다. 10번이면 끝납니다. |
| 과제 2 | 이름, 전화번호, 날짜, 부서(선택 목록), 동의 체크, "보내기". 빈 칸이 있으면 어느 칸인지 알려 줍니다. 실제로 어디에도 보내지 않습니다. |
| 자동 기록 | 시작부터 끝까지 걸린 시간, 차례가 아닌 버튼을 누른 횟수(잘못 누름), 버튼이 아닌 곳을 누른 횟수(헛누름) |
| 결과 표 | 과제가 끝날 때마다 한 줄씩 쌓입니다. 페이지를 닫았다 열어도 남습니다. "결과 복사"로 표를 복사해 프로젝트 대화에 붙여 넣습니다. "기록 지우기"는 두 번 눌러야 지워집니다. |

- 양식 과제의 잘못 누름(다른 칸에 들어간 글자 등)은 페이지가 셀 수 없어 진행자가 셉니다.
- 과제 중에는 시작 버튼이 잠깁니다. 스페이스바를 잘못 눌러 과제가 처음부터 다시 시작되지 않게 하려는 것입니다. 중간에 그만두려면 페이지를 새로 고칩니다(결과 표는 남습니다).

## 순서 (한 번에 30~40분)

**쉬는 시간을 꼭 둡니다.** 이용자가 힘들다고 하면 바로 멈추고, 멈춘 곳을 기록표에 적습니다.

### 0. 설명 (5분)

- [쉬운 사용 설명서](guide.md) 1~3번만 같이 봅니다.
- 연습으로 아무 버튼이나 몇 번 눌러 봅니다. 연습은 기록하지 않습니다.

### 1. 작은 버튼 10개 누르기 (TEST-01)

같은 과제를 세 가지 방법으로 합니다. 방법마다 **2번씩** 하고, 사이에 1분 쉽니다.

| 순서 | 방법 | 하는 법 |
|---|---|---|
| 1-A | 도우미 없이 | 도우미 아이콘 → 1번 카드로 끄고 마우스로만 |
| 1-B | 자석 커서 | 도우미 켜고, 근처로 가져가서 스페이스바(또는 클릭) |
| 1-C | 번호표 | F 키 → 번호 키. 번호가 없으면 0 키 |

기록: 걸린 시간, 잘못 누른 횟수, 헛누름(아무것도 안 눌림) 횟수

### 2. 양식 하나 채우기 (TEST-01)

| 순서 | 방법 |
|---|---|
| 2-A | 도우미 없이 |
| 2-B | 도우미 켜고 (자석 커서·번호표 중 편한 것) |

적을 내용은 미리 종이에 써 둡니다(예: 이름 "홍길동", 전화 "010-0000-0000").
글자 칸에서 "입력 중" 표시가 보이는지, Esc로 "도우미"로 돌아오는지 봅니다.

기록: 걸린 시간, 잘못 누른 횟수, 다른 칸에 글자가 들어간 횟수

### 3. 기능 하나씩 써 보기 (시간 재지 않음)

각 줄에 "됨 / 안 됨 / 불편함"과 이용자 말을 적습니다.

| 번호 | 해 볼 것 | 볼 것 |
|---|---|---|
| 3-1 | 위험한 버튼을 번호로 고르기 → Esc로 그만두기 | 빨간 확인 화면이 뜨는가, 처음 1초 동안 눌러도 안 눌리는가 |
| 3-2 | 위험한 버튼을 번호로 고르기 → Enter로 누르기 | Enter로 눌리는가 |
| 3-3 | 같은 화면에서 스페이스바 1초 꾹 누르기로 확인 | 1초가 너무 길거나 짧지 않은가 |
| 3-4 | 위험한 버튼 근처로 마우스 가져가기 | 끌려가지 않는가, 빨간 점선이 보이는가 |
| 3-5 | 머무르기 클릭 켜고(아이콘 → 3번) 버튼 위에 가만히 있기 | 원이 차오르고 눌리는가, 원치 않을 때 눌리지 않는가 |
| 3-6 | 끌어 놓기 두 번 누르기 켜고(아이콘 → 4번) 하나 옮기기 | 두 번 눌러서 옮겨지는가 |
| 3-7 | 도우미 끄고 켜기(아이콘 → 1번) | 바로 꺼지고 켜지는가 |

끝나면 머무르기 클릭과 끌어 놓기를 다시 끕니다.

### 4. 이야기 나누기 (5분)

- 가장 편했던 것, 가장 힘들었던 것
- 매일 쓰는 사이트에서 가장 먼저 되면 좋겠는 것
- 다음 단계 후보 중 무엇이 급한지: 화면 내리기(방향키)·명령 메뉴 / 자주 쓰는 말 / 틀(따라 하기) / 할 일 판 / AI 화면 정리

## 기본값 맞추기: 보이면 적을 것

진행자가 아래 모습을 볼 때마다 횟수를 셉니다. 개발자는 이 표로 기본값을 고칩니다.
(지금은 이 값을 화면에서 바꿀 수 없습니다. 시험 뒤 개발자가 바꿔 새 버전을 냅니다.)

| 보이는 모습 | 뜻 | 바꿀 값 |
|---|---|---|
| 한 번 누르려 했는데 **두 번** 눌림 | 떨림 간격이 짧음 | 떨림 간격 ↑ (300ms → 400~500ms) |
| 일부러 다시 눌렀는데 **무시됨** | 떨림 간격이 김 | 떨림 간격 ↓ |
| 버튼 근처인데 **테두리가 안 생김** | 잡는 범위가 좁음 | 잡는 범위 ↑ (48px → 64px) |
| 엉뚱한 옆 버튼이 **잡힘** | 잡는 범위가 넓음 | 잡는 범위 ↓ |
| 테두리가 **자꾸 옆 버튼으로 옮겨 감** | 옮겨 가는 문턱이 낮음 | 옮겨 가는 거리 ↑ (24px → 32px) |
| 옆 버튼 **위를 정확히** 눌렀는데 먼저 잡혀 있던 버튼이 눌림 | 옮겨 가는 문턱이 높음(자동 시험에서 20px 버튼이 32px 간격일 때 실제로 일어남) | 옮겨 가는 거리 ↓, 또는 누른 자리 버튼을 먼저 |
| 머무르기로 **원치 않는 버튼이 눌림** | 머무르기 시간이 짧음 | 머무르기 시간 ↑ (800ms → 1,200ms) |
| 머무르기 원이 **다 차기 전에 손이 흔들림** | 머무르기 시간이 김 | 머무르기 시간 ↓ |

## 시험이 끝나면

1. 시험 페이지의 "결과 복사"로 결과 표를 프로젝트 대화에 붙여 넣고, 기록표는 사진으로 찍어 올립니다.
2. 개발자가 기본값을 고친 새 버전을 만들고, 연습 사이트 자동 시험을 모두 통과시킨 뒤 공개합니다(DIST-02).
3. 다음 순서(3~6단계)를 그대로 갈지, 바꿀지 정하고 이유를 남깁니다(TEST-03).
