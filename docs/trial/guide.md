# 손 떨림 도우미 쉬운 사용 설명서

> 중간 사용자 시험용입니다. 지금 만든 것(클릭 도우미)만 적었습니다.
> 아직 없는 기능은 맨 아래 "아직 안 되는 것"에 모았습니다.

---

## 먼저 알아 둘 것

- 마우스를 **정확히** 올리지 않아도 됩니다.
- **대충 가까이** 가져가면 도우미가 버튼을 잡아 줍니다.
- 잡힌 버튼에는 **파란 테두리**가 생깁니다.
- 손이 떨려서 두 번 눌러도 **한 번만** 눌립니다.

---

## 1. 버튼 누르기 (자석 커서)

1. 마우스를 누르고 싶은 버튼 **근처**로 가져갑니다.
2. 버튼에 **파란 테두리**가 생기는지 봅니다.
3. **스페이스바**를 누릅니다. 마우스 클릭도 됩니다.

> 테두리가 다른 버튼에 있으면 마우스를 조금 더 옮기세요.
> 손이 떨려도 테두리는 쉽게 옮겨 가지 않습니다.

---

## 2. 번호로 누르기 (번호표)

마우스를 쓰기 힘든 날에 씁니다.

1. **F 키**를 누릅니다. 버튼마다 **1~9 번호**가 붙습니다.
2. 누르고 싶은 버튼의 **번호 키**를 누릅니다.
3. 원하는 버튼에 번호가 없으면 **0 키**를 누릅니다. 다음 번호들이 나옵니다.
4. 그만두려면 **Esc 키**를 누릅니다.

> 번호는 마우스 근처 버튼, 자주 누른 버튼부터 붙습니다.

---

## 3. 글자 쓰기

1. 글자 칸을 누르면 화면 **왼쪽 아래**에 **"입력 중"** 이 보입니다.
2. 이때는 스페이스바와 숫자가 **글자로** 들어갑니다.
3. 다 썼으면 **Esc 키**를 누릅니다. **"도우미"** 로 돌아옵니다.

---

## 4. 위험한 버튼

**삭제, 취소, 반려, 로그아웃, 결재 취소** 같은 버튼은 위험한 버튼입니다.

- 위험한 버튼에는 **빨간 점선**과 **"! 위험"** 이 붙습니다.
- 마우스를 가까이 가져가도 **끌려가지 않습니다.** 버튼 **위에** 정확히 있어야 잡힙니다.
- 번호로 고르면 **빨간 확인 화면**이 뜹니다.

**빨간 확인 화면에서**

1. 처음 **1초**는 무엇을 눌러도 무시됩니다. (실수 방지)
2. 정말 누르려면 **Enter 키**를 누릅니다.
   또는 **스페이스바를 1초 동안 꾹** 누릅니다.
3. 그만두려면 **Esc 키**를 누릅니다.

> 마우스 클릭으로는 확인되지 않습니다. 일부러 그렇게 만들었습니다.

---

## 5. 가만히 있으면 눌리기 (머무르기 클릭)

처음에는 **꺼져 있습니다.**

- 켜기: 브라우저 오른쪽 위 **도우미 아이콘**을 누르고, **3번 카드**를 누릅니다.
- 켜면 버튼 위에 마우스를 **가만히** 두면 원이 차오릅니다.
- 원이 **다 차면** 눌립니다. (약 0.8초)
- 위험한 버튼은 머무르기로 **눌리지 않습니다.**

---

## 6. 끌어서 옮기기 (두 번 누르기)

처음에는 **꺼져 있습니다.**

- 켜기: **도우미 아이콘**을 누르고, **4번 카드**를 누릅니다.
- 켜면 끌지 않아도 됩니다.
  1. 옮길 것을 **한 번** 누릅니다. 왼쪽 아래에 "놓을 곳을 누르세요"가 보입니다.
  2. 놓을 곳을 **한 번** 누릅니다.
- 그만두려면 **Esc 키**를 누릅니다.

---

## 7. 도우미 끄기

방해가 되면 바로 끌 수 있습니다.

- **도우미 아이콘**을 누르고, **1번 카드**를 누릅니다.
- 다시 누르면 켜집니다.

---

## 키 한눈에 보기

| 키 | 하는 일 |
|---|---|
| 스페이스바 | 파란 테두리 버튼 누르기 |
| F | 번호표 켜기 / 끄기 |
| 1 ~ 9 | 번호 붙은 버튼 누르기 |
| 0 | 다음 번호들 보기 (번호표가 있을 때) |
| Enter | 빨간 확인 화면에서 "누르기" |
| Esc | 그만두기, 글자 쓰기에서 빠져나오기 |

---

## 아직 안 되는 것

**1단계가 끝나면 들어갈 것**

- 지금 사이트에서만 도우미 끄기 (아이콘의 2번 카드. 지금은 비어 있음)
- 도울 수 없는 화면(브라우저 설정, 웹스토어)에서 "도울 수 없음" 표시
- 화면을 크게 해도(Ctrl + 더하기) 번호표·테두리 크기 그대로 두기
- 설명서에 맞춘 글꼴

**나중 단계에서 들어갈 것 (이번 시험에서는 쓰지 않음)**

- 위·아래 방향키로 화면 내리기
- 0 키로 여는 명령 메뉴 (지금 0 키는 "다음 번호들"만 합니다)
- 글자 칸 안에서 Alt + 숫자로 고르기
- 자주 쓰는 말, 즐겨찾기, 잘못 누른 것 되돌리기
- 한 줄 양식 보기, 컨디션 모드, 따라 하기 틀, 할 일 판
- 떨림 간격·잡는 범위·머무르기 시간을 **직접 바꾸는 설정 화면**
  (이번 시험 결과로 개발자가 기본값을 바꿉니다)

**알아 둘 한계**

- "사람이 직접 누른 것만" 받는 버튼은 도우미가 대신 누르면 **안 눌립니다.** 이런 버튼은 마우스로 직접 눌러 주세요.
