# 현재 입력값 비교와 명시 재적용

기준: PR20 `243aa2c15c250ceebb0b9fc90149dd4310f1d92e`, 후속 브랜치 `codex-form-reapply-confirmation`.

## 범위와 결정

사용자의 남은 구현 계속 진행 지시를 따라 PR19 이후 문서에 남아 있던 변경된 페이지 값 재적용 확인을 구현한다. PR20에 이미 있던 native select/checkbox·일반 validity 안내는 다시 구현하지 않는다. 장기 로드맵 Phase4~6, 최근값 자동수집, 사이트 임의 오류 원문, Windows 연결은 이번 묶음에 포함하지 않는다.

기존에는 사이트 값이 바뀌면 적용을 거절하고 선택 대상을 해제했다. 이제 일반적인 적용 거절은 대상과 작성 초안을 보존하고 `현재 값과 비교`로 안내한다. 이 명령은 선택한 지원 텍스트 칸만 명시적으로 다시 읽으며, 현재 입력값과 작성 문장을 각각 24 grapheme 읽기쪽으로 보여 준다. 값 읽기만으로 페이지 변경이나 저장은 발생하지 않는다. 미완성 한글은 조합을 마친 뒤 비교하도록 안내하고 그대로 보존한다.

확인 화면은 취소를 먼저 두고 기존 1초 보호와 새 Space down/up 계약을 사용한다. `확인 · 입력칸에 적용`은 비교 당시 대상·identity·현재값·작성문장·선택범위 스냅샷으로 한 번 요청한다. 기존 receiver의 문서·승인 세대·가시성·민감칸·값 검사도 그대로 적용한다. 확인 중 값이 또 바뀌면 거절한다. 취소는 초안을 보존하고 편집으로 돌아가며, 명시/자동 쉬기·모드 변경·끄기는 확인안을 폐기한다. 결과 불명은 대상 해제와 일시정지로 안내하며 자동 재시도하지 않는다. 이 흐름은 검색이나 제출을 호출하지 않는다.

기존 디자인의 확인 작업판·토큰·문구 읽기쪽을 재사용하며 새 시각 토큰·의존성·권한은 없다. 브라우저 메모리에만 비교값을 보관한다. 기존 양식 초안/진입 전 작업공간과 downloads ZIP, 관련 없는 PR들은 보존한다.
