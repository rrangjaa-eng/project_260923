# 단일 스위치 1차 실제 PC 검증 인계

자동 검증과 별도로 확인할 항목이다. 아래 항목은 현재 **미실행**이며, 실사이트 선정 때문에 클라우드 구현·자동 검증을 보류하지 않는다. 2차 파일 선택창·브라우저 밖 조작·휴대용 실행기는 포함하지 않는다.

## 준비와 완료 기준

확장 설치·사이트 권한·단일 스위치 방식 선택은 준비 단계에서 확인한다. 준비가 끝난 지원 페이지에서는 스페이스바를 한 번 누르고 놓는 동작만으로 한글 문장 작성 → 검색 → 결과 선택 → 읽기·스크롤 정지 → 뒤로 → 다른 지원 탭 이동을 마친다. 길게 누르기·더블클릭·조합키·정밀 마우스 이동을 필수로 사용하지 않는다.

첫 실사이트는 사용자가 실제로 이용하는 일반 검색·읽기 사이트 한 곳을 선정한다. 클라우드의 연습 사이트 통과를 해당 실사이트의 통과로 바꾸지 않는다. 시작 속도는 항목당 1.5초, 입력 간격 보호 300ms다. 첫 항목은 두 배 시간을 주며, 작업판의 `조절·쉬기`에서 속도 0.8~4초와 보호 100~1000ms를 명시적으로 조정할 수 있다. 수치는 초기값이며 실제 사용성 합격 기준이 아니다.

## 실제 검증 기록

| 항목 | 재현·관찰 | 기록할 결과 |
|---|---|---|
| Space 전체 활동 | 저장 문구에 없는 한글 문장을 만들고 중간 수정·공백을 넣어 검색/읽기 여정을 완료 | 성공 여부, 필수 다른 조작 여부, 예상 밖 클릭·제출 횟수 |
| 입력 위치와 복원 | 일반 input/textarea의 중간 선택을 기억한 뒤 쉬기·재개, `원래 입력칸으로`, 선택 교체·적용 | 값·선택 범위·초점, 초안 보존, 사이트 자체 이벤트 부작용 |
| 오선택·피로·속도 | 실제 사용자가 편한 속도와 보호를 직접 선택하고 여러 번 같은 짧은 활동 수행 | 속도/보호값, 오선택·취소·쉬기 횟수와 사용자 의견. 임의 합격 수치 없음 |
| 위험 확인·무입력 | 안전한 시험 자료에서 확인 진입 후 아무 조작 없이 기다림, 이후 취소 또는 새 입력으로 확인 | 무입력 제출 0회, 새 명시 입력만 확정, 동작명 이해 여부 |
| 쉬기·초점 이탈 | 자동 스크롤 중 Space 한 번, 다른 탭/주소창으로 초점 이동 후 페이지로 복귀 | 첫 입력은 정지만, 옛 동작 재실행 0회, 재개 입력은 선택이 아님 |
| 실제 한국어 IME | 기존 키보드 입력 방식에서 MS 한국어 IME 등 실제 조합/확정과 Space를 확인하고 단일 스위치로 복귀 | 조합 Space가 작업판 선택으로 실행되지 않음, 버퍼·대상 보존 |
| 기존 마우스 보조 | 기존 마우스 방식으로 명시적으로 전환해 자석·떨림 보호·dwell 확인 | 기존 기능 보존, 한 동작의 이중 실행 여부 |
| 브라우저·권한 | 실제 설치 프로필에서 Chrome부터 확인하고 사용 예정인 Edge/Whale를 별도 확인 | OS/브라우저/확장 커밋/사이트/권한과 각각의 결과 |

페이지 밖 주소창·브라우저 메뉴·OS 대화상자에서 전역 Space 정지를 보장하지 않는다. 일반 입력칸 및 GET 검색 form이 첫 지원 범위이며, rich editor 직접 삽입·파일 창·모든 사이트 지원은 약속하지 않는다. 비밀번호·민감칸은 단일 스위치 초안/문구 수집 대상에서 제외한다.

## 다음 결정

첫 실사이트와 실제 PC의 OS·브라우저를 정한 뒤 위 표에 결과를 기록한다. 자동 검사 통과, 실제 사용자 합격, 2차 착수를 별개로 판단한다. 현 상태와 자동 검사 근거는 [현황](../WORK-STATUS.md) 및 [검증 기록](2026-10-01-single-switch-phase1.md)을 기준으로 한다.


## NAV-02 후속 실제 PC 확인 — 미실행

대상은 draft PR30 `af487cb`이며 기존 배포 ZIP에 포함되었다는 뜻이 아니다. 승인된 설치·검증 환경에서 제품 커밋을 먼저 기록한다. 아래는 실제 PC 관찰 절차이며, 클라우드의 합성 Chromium 검사와 구분한다. 민감한 업무 자료 대신 시험 문장과 일반 읽기 페이지를 사용한다.

| 항목 | 실제 PC에서 할 일 | 기록할 결과 |
|---|---|---|
| 새 탭과 검색 | Space로 새 탭을 열고 저장 문구에 없는 한글 검색어 작성 → 입력칸 적용 → 명시 검색 | 새 탭 1개, 기존 탭·초안 보존, 적용 전 입력값 불변, 검색 전 이동 없음, 필요한 다른 조작 |
| 주소 이동 | 시작 화면의 영문·숫자·주소 기호 선택으로 시험 HTTP(S) 주소 작성·적용 후 이동 확인 | 표적 선택·문장 수정 부담, 명시 확인 전 이동 없음 |
| 초안 보호 | 미완성 한글과 다른 양식 칸의 미적용 문장을 각각 남겨 새로고침·닫기 선택 | 문장 보존, 작업 차단과 안내 이해 여부. 기존 “문장 버리기” 뒤 원래 값과 차이가 남으면 계속 차단될 수 있음 |
| 새로고침 확인 | 미적용 작업 없는 시험 페이지에서 취소, 이후 다시 선택해 새 입력으로 확인 | 취소 시 문서 유지, 확인 시 한 번만 새로고침, native 경고가 뜨면 그 화면과 별도 조작 기록 |
| 닫기와 돌아가기 | 같은 창에 시험 탭 2개를 두고 복귀 탭 이름 확인 → 취소 → 다시 명시 확인 | 선택한 source만 닫힘, 표시한 탭으로 복귀, 정지 안내 및 새 Space 재개 이해 여부 |
| 마지막 탭 | 다른 창이 있는 경우와 없는 경우 각각 현재 창의 마지막 탭에서 닫기 선택 | 창을 닫지 않음, 거절 안내 이해 여부 |
| 피로와 회복 | 편한 속도로 위 여정을 수행하고 오선택 시 취소·쉬기·재개 | 소요 시간, 오선택·취소·쉬기 횟수와 사용자 의견. 자동 검사로 합격 수치를 대신 정하지 않음 |

시작 페이지가 아닌 주소창·native 경고·설치 UI까지 Space로 제어된다고 간주하지 않는다. 결과 불명 안내가 나오면 실행이 일어났는지 관찰하고 자동 재시도를 기대하지 않는다. 실제 Windows IME 확인은 위 기존 키보드 방식 항목을 별도로 수행한다.
