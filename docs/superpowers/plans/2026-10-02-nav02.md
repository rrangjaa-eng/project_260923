# NAV-02 승인 정책 구현 계획

> 실행: 같은 세션에서 직접 구현, TDD와 독립 검토. 사용자가 세 정책을 승인하고 구현·커밋·push·draft PR·최종 CI까지 요청했다. 추가 형식 승인을 반복하지 않는다.

**목표:** Space로 도우미 새 탭, 미적용 작업을 보호하는 새로고침, 돌아갈 탭을 확인하는 닫기.
**기반:** PR29/04373f8 + 최종 증거 d0da218. PR27–29는 미병합.
**구조:** 기존 Space controller·engine·worker 승인 경로 확장. 시작 화면은 확장 내부 문서이며 기존 한국어 편집과 명시 실행을 재사용. 별도 권한·자동 외부 전송·저장 확장 없음.
**승인 설계:** [기존 결정 문서](../../verification/2026-10-02-nav02-remaining-decisions.md)의 세 추천에 사용자 “네가 추천하는대로 해”.

## 공통 제약
- 초안·조합·양식의 다른 칸 초안·진행 작업·unknown 상태를 보존한다. 미적용 문장이나 미확정 작업이 있으면 reload/close 차단·안내.
- 새 탭은 사용자 명시 선택으로만 생성하고 자동 검색하지 않는다. 시작 화면은 Space 선택과 한글 입력을 지원한다.
- 같은 창의 마지막 탭은 다른 창이 있어도 닫지 않는다. 같은 창의 지원되는 돌아갈 탭을 미리 보여 주고 새 누름으로 확인한다. 대상 변경 시 거절한다.
- 문서/모드/실행ID·취소 epoch·일회 실행 소비 유지. unknown 자동 재시도 금지.
- main/다른 PR/ZIP 보존. merge/deploy 금지. .planning/CLAUDE/dependency/permission 변경 없음.

## 실행 증분
- [x] 공통 보호: controller에서 미적용 workspace/양식 초안/unknown 판정. worker reload/close-preview/close 스키마·일회 승인·same-window 최신 대상 검증. 단위 RED→GREEN.
- [x] Space 메뉴: 취소 우선·1초 보호 후 새 누름 확인. 초안 차단 안내, 돌아갈 탭 미리보기. controller와 실제 탭 E2E.
- [x] 도우미 시작 화면: 정확한 내부 URL에 한정한 통신, 기존 엔진/한글 편집 재사용, 명시 검색·페이지 이동. sender/교체/연결 끊김 검사.
- [x] 독립 코드/권한/디자인 검토, 타입·린트·단위·관련 E2E·UI, 커밋/push/draft PR, 최종 전체 CI 종료 확인.

## 집중 검증
1. 숨은 양식 칸/복구 문장/미완성 한글/unknown 상태는 reload·close를 막는다.
2. 마지막 탭(복수 창 포함), 다른 창·지원 불가 탭만 남음, preview 뒤 대상 이동/삭제/문서 교체는 닫지 않는다.
3. 승인/조회 응답 지연 중 쉬기·문서 교체·중복 요청은 효과 없음.
4. API 효과 뒤 응답 유실은 unknown·자동 재실행 없음.
5. 시작 화면의 변조/다른 확장 페이지 sender와 끊긴 연결은 거절; 명시 선택 전 외부 요청 없음.
