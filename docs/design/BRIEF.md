# 디자인 브리프 — 손 떨림 브라우저 도우미

작성: 2026-09-23 · `docs/DESIGN.md` §1 · 입력: `.planning/PROJECT.md`, `.planning/REQUIREMENTS.md`, 설계 문서(`docs/superpowers/specs/2026-09-23-tremor-browser-helper-design.md`)

```
제품이 하는 일(한 문장):
  손 떨림이 있는 이용자 한 사람이 어느 사이트에서든 원하는 것을 대충 가져가거나 키 한두 번으로 누르고,
  반복 업무 양식은 "틀 1 + 값 2~3 + 확인 1"로 끝내게 돕는 브라우저 확장.

주 사용자 / 사용 상황:
  뇌병변 장애로 손 떨림·불수의 운동이 있는 이용자 1명. 윈도우 PC, 크롬·엣지·웨일.
  하루 종일 업무(그룹웨어·ERP·전자결재)와 평소 사이트를 오간다. 급하다 — 평소 속도가 가장 중요.
  손을 거의 못 쓰는 날이 있다. 보조기기·웹캠 없음.

가장 잦은 작업 3개:
  1. 작은 버튼·링크·이미지 누르기 (자석 커서, 번호표)
  2. 긴 양식 채우기 (입력 줄이기, 양식 한 장 보기)
  3. 반복 업무 틀 실행과 제출 확인

성공 기준:
  빠름 + 믿음. 잘못 눌리지 않는다는 확신, 되돌릴 수 없는 일은 확인 뒤에만.

브랜드·회사 톤:
  없음. 이용자 개인 도구.

제약:
  - 모든 화면은 남의 사이트 위에 뜨는 오버레이다. 밝은 사이트·어두운 사이트 어디서든 보여야 한다.
  - 시력: 확인되지 않음 → "크게, 색만으로 구분하지 않기"(모양·글자·테두리를 함께 쓴다).
  - 대비: 글자 4.5:1 이상, 테두리·아이콘 3:1 이상. 누르는 대상은 크게.
  - 다크모드: 요구 없음. 단 오버레이는 어두운 사이트 위에서도 보여야 한다.
  - 한국어 단일. 키보드만으로 모든 동작. 움직임 줄이기 설정 존중.

피해야 할 것:
  - 사이트를 가리는 큰 패널, 번쩍이는 효과, 장식.
  - 색만으로 상태 구분.
  - `docs/DESIGN.md` §5 안티슬롭 목록.

디자인의 핵심 질문 — "이 화면이 사용자에게 무엇을 느끼게 해야 하나":
  "지금 무엇이 잡혔고, 무엇을 누르면 무슨 일이 일어나는지 한눈에 안다. 서두르지 않아도 틀리지 않는다."

느낌(사용자 선택 A):
  차분하게. 사이트를 가리지 않고, 필요한 것만 뚜렷하게.
```

## 이 브리프가 다루는 화면
- 자석 커서 강조 테두리, 머무르기 진행 표시
- 번호표(1~9)와 자동 순서 강조
- 입력 모드 표시("입력 중 / 도우미")
- 명령판(0)과 번호 카드, 키 안내 카드
- 확인 화면(제출 확인, 위험한 버튼 확인)
- 작업판, 양식 한 장 보기, 틀 저장·실행 화면, 설정·맞춤 설정
