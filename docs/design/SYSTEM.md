# SYSTEM.md — 손 떨림 브라우저 도우미 디자인 기준

작성: 2026-09-23 · `docs/DESIGN.md` §3 · 채택: 안 A 등대 (`EXPLORE.md`, 사용자 선택) · 토큰: `docs/design/tokens.css`
실물: 디자인 캔버스의 "A 등대" 두 화면 https://claude.ai/artifact/BDc2DWcg7eBRQZim2LETiS

## 방향
**등대.** 한 줄 원칙: *남의 사이트 위에서, 지금 잡힌 것과 다음에 일어날 일만 또렷하게.*

채택 이유
1. 브리프의 "차분하게, 사이트를 가리지 않고"에 가장 맞다.
2. 흰 후광 덕분에 밝은 사이트와 어두운 사이트 모두에서 같은 모양으로 보인다.
3. 가장 적은 요소로 만들 수 있어 모든 프레임에 넣어도 가볍다.

흡수한 것: 안 B의 "잡힌 곳이 가장 먼저 보임" → 강조 테두리를 5px로 굵게 한다.

## 오버레이의 바탕 규칙
- 도우미가 그리는 모든 것은 **Shadow DOM 안**에 있고, 사이트의 CSS를 받지도 주지도 않는다.
- 사이트 위에 떠 있는 표시(번호표, 테두리, 모드 표시)는 **항상 흰 후광 2px**을 두른다. 남색은 어두운 사이트 위에서 대비가 1.2:1로 떨어지지만, 흰 후광은 16.5:1이라 경계가 보인다. 밝은 사이트에서는 남색이 14.1:1.
- 상태는 **색만으로 구분하지 않는다.** 위험 = 빨강 + 점선 + "! 위험" 글자, 잡힘 = 굵은 테두리, 입력 중/도우미 = 모드 글자.
- 도우미 화면은 사이트보다 위(`z-index` 최대)지만, 확인 화면이 아닐 때는 사이트를 덮는 면(배경)을 만들지 않는다.

## 글자
- 서체: **IBM Plex Sans KR** (한글·라틴·숫자 하나로). 확장 안에 파일로 넣는다(OFL). 없으면 `'Malgun Gothic', sans-serif`.
- 숫자: `font-variant-numeric: tabular-nums` (금액·날짜·번호표).
- 스케일(px): 번호표 18 · 작은 글 15 · 본문 18 · 값 22 · 제목 30 · 큰 키 22. 15px 아래는 쓰지 않는다.
- 굵기: 400 본문, 700 번호표·제목·값·버튼. 두 단계만.
- 행간 1.6, 자간 -0.01em, `word-break: keep-all`.
- 금액 `128,000원`, 날짜 `2026-09-23`, 시간 `14:05`.

## 간격
- 기본 단위 8. 스케일: 4 · 8 · 12 · 16 · 24 · 32 · 40.
- 확인 카드 폭 600px(화면이 좁으면 화면 폭 − 32px), 안쪽 여백 36px 40px.
- 명령판: 3열 카드 격자, 카드 사이 16px.

## 형태
| 대상 | radius | 테두리 |
|------|--------|--------|
| 번호표 | 6 | 후광 2px |
| 강조 테두리 | 8 | 남색 5px + 안팎 흰 후광 2px |
| 버튼·키 표시 | 10 / 6 | 주 버튼 없음, 보조 버튼 남색 3px |
| 카드(명령판·작업판) | 12 | 선택 시 남색 3px |
| 확인 카드 | 14 | 남색 3px |
- 그림자는 쓰지 않는다(후광과 테두리로 구분).

## 크기 (떨림 이용자 기준)
- 번호표 28×28 이상. 누르는 대상(버튼·카드) 높이 56px 이상, 확인 화면 버튼 64px.
- 자석 커서의 잡는 범위는 요소보다 넓다(값은 맞춤 설정에서). 테두리는 요소보다 8px 바깥에 그린다.
- **브라우저 확대와 상관없이 크기 고정**(디자인 검토 5번): 사이트를 Ctrl +/−로 확대·축소해도 번호표·테두리·모드 표시·카드는 화면에서 같은 크기다(페이지 확대 비율만큼 거꾸로 맞춘다). 크기는 컨디션 모드의 "표시 크기"로만 바꾼다.
- 번호표 배치: 요소 왼쪽 위 모서리 바깥(−14px, −14px). 다른 번호표와 겹치면 오른쪽 위 → 왼쪽 아래 → 오른쪽 아래 순서로 옮긴다. 넷 다 겹치면 요소 안쪽 왼쪽 위.
- 번호표 배치 — 화면 밖·위험 표시(/qa 2026-09-26 ISSUE-002·003, 사용자 결정): 화면(뷰포트) 밖으로 나가는 자리와 위험한 요소의 "! 위험" 표시를 가리는 자리도 겹침과 똑같이 건너뛴다(위험 표시를 먼저 자리 잡아 다른 번호표가 피하게 한다). 네 자리와 요소 안쪽까지 모두 안 되면 겹침보다 잘림을 더 나쁘게 보고 화면 안으로 밀어 넣는다(잘림 0 우선).
- 번호표 배치 — 도우미 자신의 표시(/design-review 2026-09-26 3회차 F4, 사용자 결정): 도우미 자신의 모드 표시(왼쪽 아래)와 "다음" 카드도 다른 번호표처럼 장애물로 피한다(그 순간 화면에 있을 때만).

## 모션
| 무엇 | 시간 | 이징 |
|------|------|------|
| 강조 테두리 이동(잡힘 바뀜) | 80ms | ease-out |
| 머무르기 진행 원이 차오름 | 설정한 머무르기 시간(기본 0.8초) | linear |
| 확인 보호 막대 | 1초 | linear |
| 카드·확인 화면 나타남 | 120ms | ease-out, 투명도만 |
- 금지: 튀는 효과, 흔들림, 깜빡임, 화면 전체 이동, 반복 애니메이션.
- `prefers-reduced-motion: reduce`: 이동·나타남은 즉시. 머무르기 원과 보호 막대는 남긴다(시간을 알려 주는 정보라서).

## 오버레이 템플릿
**평소 화면** (사이트 + 표시)
```
[8]지출결의          [1]상신 [2]임시저장 ⟦검색⟧ ← 잡힘(5px)
                     ┆삭제┆ ! 위험
┌────────────────────────────────────┐
│ ■ 도우미   스페이스바 누르기, 0 명령판 │ ← 모드 표시(왼쪽 아래)
└────────────────────────────────────┘
```
**확인 화면** (제출·위험 버튼)
```
░░░░░░░ 사이트(어둡게) ░░░░░░░
░  ┌ 지출결의서를 상신할까요? ┐  ░
░  │ 금액   128,000원          │  ░
░  │ ▓▓▓▓▓▓░░ 1초 뒤에 누를 수 있어요 │
░  │ [Enter 상신]   [Esc 취소] │  ░
░  └──────────────────────────┘  ░
```
**명령판·작업판** (가운데 큰 카드 격자)
```
┌ 명령판 ─────────────────────────┐
│ 키 안내: 스페이스바 1~9 0 ↑↓ Esc  │
│ [1 뒤로] [2 작업판] [3 틀 실행]   │
│ [4 조작 방식] [5 입력 되돌리기] [6 컨디션] │
│ [7 새로고침] [8 도우미 끄기] [9 다음] │
└──────────────────────────────────┘
```
- 카드 자리는 **고정**이다(디자인 검토 1번, 사용자 결정). 자주 쓰는 8개를 첫 장 1~8에 늘 같은 자리로 두고 9는 "다음 장". Esc는 이전 장 또는 닫기.
  - 첫 장: 1 뒤로 · 2 작업판 · 3 틀 실행 · 4 조작 방식 바꾸기 · 5 입력 되돌리기 · 6 컨디션 모드 · 7 새로고침 · 8 도우미 끄기
  - 둘째 장: 1 앞으로 · 2 탭 닫기 · 3 새 탭 · 4 틀 기록 · 5 번호 고정 · 6 양식 한 장 보기 · 7 화면 정리(AI) · 8 더블클릭
  - 셋째 장: 1 끌어서 놓기 · 2 민감칸 설정 · 3 기록 내보내기 · 4 맞춤 설정 다시 하기
- 이용자는 설정에서 카드 자리를 바꿀 수 있다. 바꾼 자리도 고정이다(쓰는 횟수로 저절로 움직이지 않는다).

**양식 한 장 보기** (한 줄에 한 칸, 라벨 크게)
```
┌ 양식 한 장 보기 ───── [Esc 원래 화면으로] ┐
│ 날짜  [ 2026-09-23          ]          │
│ 금액  [ 128,000             ]          │
│ 적요  [ 거래처 미팅 식대    ]          │
└────────────────────────────────────────┘
```

## 컴포넌트 규칙
- **버튼 위계:** 1차 = 남색 채움 + 흰 글자(한 화면에 하나), 2차 = 흰 바탕 + 남색 3px 테두리, 3차 = 글자만(밑줄). 위험 = 빨강 채움, 확인 화면 안에서만.
- **키 표시:** 버튼 안 왼쪽에 키 이름을 테두리 칩으로(`Enter`, `Esc`, `1`). 모든 버튼에 누를 키를 적는다.
- **번호 카드:** 큰 숫자(22px, 700) + 이름. 선택되면 남색 3px 테두리.
- **입력·오류:** 오류는 칸 아래에 `--danger` 글자 + "!" 표시, "무엇이 문제 + 다음 행동" 한 문장.
- **상태:** 빈 상태 = 한 문장 + 할 수 있는 다음 행동 카드. 불러오는 중 = "불러오는 중" 글자(돌아가는 아이콘 없음). 막힘·확인 필요 = `--warning` 테두리 카드 + 이유 + 번호 선택지.
- **알림(토스트):** 화면 오른쪽 아래, 4초. 같은 동작은 버튼과 같은 단어("저장했어요" ↔ "저장").
- **모드 표시:** 기본 자리는 왼쪽 아래. "도우미" = 남색 네모, "입력 중" = 남색 테두리만 + "Esc로 도우미". 글자 18px.
  - 커서(또는 잡힌 요소)가 모드 표시에서 80px 안으로 오면 오른쪽 아래로 비켜 가고, 커서가 떠나도 그 자리에 머문다. 다음에 커서가 다가오면 다시 반대편으로 옮긴다(디자인 검토 4번). 옮김은 120ms, 움직임 줄이기 설정이면 즉시.
  - 확인 대기가 있으면 모드 표시 오른쪽에 "확인 대기 1" 칩(남색 테두리, 숫자 굵게)을 붙인다. 확장 아이콘에도 같은 숫자 배지를 단다. 지금 화면에 확인 창을 바로 띄우지 않는다(디자인 검토 6번).

## 카피 규칙
- 버튼은 실제 동작 단어: "상신", "저장", "취소". "확인"·"제출" 같은 빈말은 쓰지 않는다(사이트 버튼 이름을 그대로 가져온다).
- 질문은 "…할까요?", 알림은 "…했어요", 오류는 "원인. 다음 행동." 사과하지 않는다.
- 같은 행동은 어디서나 같은 단어. 키 이름은 영어 그대로(`Enter`, `Esc`), 스페이스바만 한글.

## 아이콘
- 세트 하나: Lucide(선 아이콘, 새 의존성이라 구현 때 승인 후 도입), 굵기 2px 고정, 크기 20·28 두 단계. 아이콘만 있는 버튼은 만들지 않는다(항상 글자와 함께).
