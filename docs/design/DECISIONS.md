# 디자인 결정 기록

## 2026-09-23
- **채택: 안 A 등대** (사용자 선택). 이유: 브리프의 "차분하게"에 가장 맞고, 흰 후광으로 밝은·어두운 사이트 모두에서 또렷하며, 가장 가볍다.
- **흡수:** 안 B의 "잡힌 곳이 먼저 보임"을 강조 테두리 5px로 가져왔다.
- **버림: 안 B 형광펜.** 노란 사이트·어두운 사이트에서 띠가 약해지고, 브리프의 차분함과 가장 멀다.
- **버림: 안 C 계기판.** 사이트를 늘 좁히고, 눈이 패널과 사이트를 오가야 하며, 사이트 위 번호 원(22px)이 떨림 이용자에게 작다.
- **과정:** `/design-shotgun` 이미지 생성은 키가 없어 HTML 시안(디자인 캔버스)으로 대신했다(사용자 승인). 캔버스의 A 두 화면을 `/design-html` 결과물로 쓴다.
- **서체:** IBM Plex Sans KR을 확장에 파일로 넣는다(OFL). 시안에서 쓴 서체를 그대로 유지.
- **그림자 없음:** 사이트마다 바탕이 달라 그림자는 보이지 않거나 지저분해진다. 후광과 테두리로 구분한다.
