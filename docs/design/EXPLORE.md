# 디자인 발산 — 오버레이 시안 3개

작성: 2026-09-23 · `docs/DESIGN.md` §2 · 브리프: `docs/design/BRIEF.md`
실물: 디자인 캔버스(비공개) https://claude.ai/artifact/BDc2DWcg7eBRQZim2LETiS — 안마다 "평소 화면"(번호표·자석 커서·위험 버튼·모드 표시)과 "확인 화면"(상신 확인)
`/design-shotgun` 이미지 생성은 키가 없어 HTML 시안으로 대신했다(사용자 승인, 2026-09-23).

모든 안의 공통: 가짜 그룹웨어 "지출결의서" 위에 같은 요소(1 상신 … 9 달력)에 번호표, "검색" 버튼이 자석 커서에 잡힌 상태, "삭제"는 위험 버튼. 확인 화면은 Enter/Esc 키 표시와 1초 보호 막대.

---

안 A — 등대 [안전]
축 값: 톤 절제 / 밀도 여백 / 색 무채+남색 1 / 타입 산세리프 단일 / 형태 둥근 사각 / 구조 떠 있는 칩·가운데 카드 / 모션 응답형만 / 메타포 도구
색: 남색 #1B2B4B(번호표·테두리·주 버튼), 흰 #FFFFFF(후광 2px·카드), 빨강 #B42318(위험), 회청 #4A5568(보조 글자), 옅은 회 #E3E6EC(구분선), 어둡게 rgba(15,23,38,.45)(확인 화면 뒤)
서체: IBM Plex Sans KR (한글·숫자)
레이아웃: 요소 왼쪽 위 모서리에 28px 남색 번호 칩, 잡힌 요소는 4px 남색 + 흰 후광 테두리, 모드 표시는 왼쪽 아래. 확인은 화면 가운데 600px 카드, 뒤는 어둡게.
```
┌ 사이트 ─────────────────────────┐
│ [1]상신  [2]임시저장  ⟦검색⟧    │
│             ┌ 상신할까요? ┐     │
│             │ 금액 128,000 │     │
│ [도우미]    │[Enter 상신][Esc]│  │
└─────────────┴──────────────┴────┘
```
핵심 질문에 답하는 방식: 흰 후광 덕분에 밝은·어두운 사이트 모두에서 번호와 테두리가 또렷하고, 확인 화면은 다른 것을 다 가려 한 가지 결정에만 집중하게 한다.
과감함을 쓴 한 곳: 없음(가장 안전한 안). 굳이 꼽으면 확인 화면의 큰 키 표시.
위험·비용: 가장 무난하다. 번호 칩이 작은 요소 여럿이 붙은 곳에서 겹칠 수 있다(배치 규칙 필요).

안 B — 형광펜 [과감]
축 값: 톤 표현적 / 밀도 중간 / 색 노랑+검정 / 타입 산세리프 굵게 / 형태 직각·선 / 구조 옆 띠 / 모션 없음 / 메타포 문서(종이에 형광펜)
색: 노랑 #FFD43B(잡힘 띠·번호표·주 버튼), 먹 #1A1A1A(테두리·글자), 빨강 #C81E1E(위험 빗금), 종이 #FFFDF5(확인 띠)
서체: IBM Plex Sans KR
레이아웃: 잡힌 요소 뒤에 노란 형광펜 띠 + 굵은 밑줄, 번호표는 요소 위 노란 사각 꼬리표. 확인은 오른쪽 400px 띠로 사이트를 덜 가린다.
```
┌ 사이트 ───────────────┬ 상신할까요? ┐
│ ▇검색▇  [5]          │ 금액        │
│ ‗‗‗‗‗‗                │ 128,000원   │
│ ▨삭제▨ !위험          │ [Enter 상신]│
└───────────────────────┴─────────────┘
```
핵심 질문에 답하는 방식: "지금 잡힌 곳"이 종이에 칠한 것처럼 가장 먼저 눈에 들어온다.
과감함을 쓴 한 곳: 잡힌 요소 위의 노란 띠(사이트 색과 섞임).
위험·비용: 노란 사이트·어두운 사이트에서 띠가 약해진다. 브리프의 "차분하게"와 가장 멀다.

안 C — 계기판 [밀도]
축 값: 톤 절제 / 밀도 정보 / 색 어두운 회+청록 1 / 타입 산세리프 / 형태 직각·작은 원 / 구조 오른쪽 고정 패널 / 모션 응답형만 / 메타포 도구(콘솔)
색: 그래파이트 #20242B(패널), 청록 #2DD4BF(번호·잡힘·주 버튼), 밝은 글자 #E8ECF1, 보조 #A9B2BE, 산호 #F97066(위험)
서체: IBM Plex Sans KR
레이아웃: 오른쪽 320px 패널에 1~9 목록(이름과 함께), 사이트 요소에는 작은 22px 번호 원만. 확인도 패널 안에서 한다. 사이트는 그만큼 좁아진다.
```
┌ 사이트(좁아짐) ──────┬ 도우미 ──────┐
│ 검색⑤ 추가⑥        │ ① 상신       │
│ 상신① 삭제          │ ⑤ 검색 ◀잡힘 │
│                      │ Enter 상신   │
└──────────────────────┴──────────────┘
```
핵심 질문에 답하는 방식: 무엇이 몇 번인지 이름으로 적혀 있어 확실하다.
과감함을 쓴 한 곳: 사이트 옆을 늘 차지하는 패널.
위험·비용: 사이트를 늘 좁힌다(반응형 사이트는 배치가 바뀜). 눈이 패널과 사이트를 오가야 해서 느릴 수 있다. 작은 번호 원은 떨림 이용자에게 작다.
