# 단일 스위치 수정본 교체·시작·종료 안내

**이 과거 ZIP의 검증 기록:** CI65에서 단위148건·E2E305건 전부 통과했다. 전달 ZIP을 직접 압축 해제해 새 Chromium 프로필에 설치한 추가 smoke도 1/1 통과했다(58.3초). 실제 팝업 Space 시작 → 한글 ‘가’ 조합·검색 → 결과 본문 읽기·자동 스크롤 → 팝업 즉시 정지 → 일반 문자·Space 입력 복구를 확인했다. 시작을 우회하는 저장소 직접 변경은 하지 않았다.

이 안내는 설치본 시작·종료 오류를 수정한 빌드용이다. 이전 `9741b0c` ZIP과 구 안내서를 다시 사용하지 않는다. 이 ZIP의 고정 제품 SHA와 당시 검사 결과는 이 안내를 따른다. 작업 현황표의 후속 기능·CI는 이 ZIP에 포함되지 않는다.

수정 제품 SHA: `3ae6ad29fd3e77e43cdb68c51d540035e1002b16`. 새 팝업의 ‘활동 선택 시작’과 ‘즉시 정지 · 도우미 전체 종료’가 구버전과 구분되는 표시다.

## 교체

1. 브라우저 확장 관리에서 기존 **손 떨림 도우미**를 끈다. 잔여 동작이 있으면 사용하던 페이지를 새로고침한다.
2. 이전 도우미를 제거한다. 새 ZIP을 다른 폴더에 압축 해제한다. 예전 폴더 파일을 일부 덮어쓰거나 두 버전을 함께 로드하지 않는다.
3. Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드**를 선택한다. 새 폴더에서 `manifest.json`이 바로 보이는 위치를 고른다. ZIP 자체를 고르지 않는다.
4. 확장 관리에는 도우미 하나만 남아야 한다. 교체 전 열려 있던 페이지는 새로고침해 예전 페이지 스크립트를 정리한다.

설치와 확장 관리 자체는 브라우저 UI 조작이 필요하다. 이 단계까지 Space만으로 조작할 수 있다고 보장하지 않는다. 새로운 권한을 추가한 수정본은 아니다. 클라우드의 실제 설치·비활성화 검사는 Chromium에서 수행했다. 사용자의 Chrome/Edge 프로필은 별도 검증 범위다.

## 시작

1. 일반 웹 탭에서 브라우저 도우미 팝업을 연다. 팝업이 열리면 **활동 선택 시작**부터 테두리가 차례로 이동한다.
2. **활동 선택 시작**에 테두리가 있을 때 스페이스바를 한 번 누르고 놓는다. 누르고 있는 동안에는 실행하지 않는다. 길게 누르기·반복 누름은 필요 없다.
3. 연결에 성공하면 팝업이 닫히고 페이지의 **스페이스바 작업판**에서 그룹 순환이 시작된다. 이제 찾기·페이지 항목·읽기·글쓰기 등의 원하는 그룹에 테두리가 있을 때 같은 동작으로 선택한다.
4. 도우미가 꺼져 있으면 팝업의 **도우미 켜기**를 먼저 선택하고, 다시 **활동 선택 시작**을 선택한다. ‘마우스 조작으로 전환’은 활동 시작이나 전체 종료 버튼이 아니다.

새 확장 설치 전에 열린 일반 탭도 **활동 선택 시작**에서 연결을 시도한다. 클라우드 HTTPS 검사에서는 새로고침 없이 성공했다. 연결 실패 안내가 나오면 그 페이지를 새로고침하고 다시 시작한다. 브라우저 설정·확장 스토어와 같은 제한 페이지는 일반 웹 탭으로 옮긴다. 연결 실패만으로 모든 페이지가 미지원이라고 판단하지 않는다.

## 끝내기

- 팝업에서 **즉시 정지 · 도우미 전체 종료**에 테두리가 있을 때 Space를 한 번 누르고 놓는다. 켜기가 대기 중이어도 이 버튼은 계속 선택할 수 있다. 저장을 기다리는 동안에도 페이지 실행을 먼저 정지하도록 수정했다.
- 페이지 안에서는 **조절·쉬기 → 도우미 끄기 · 페이지 입력 돌려주기**를 선택한다. 작업판을 지우고 정상 키·마우스 입력으로 돌려준다. **쉬기**는 다시 Space로 재개할 수 있는 휴식이며 전체 종료와 다르다.
- 자동 스크롤 중 Space 한 번은 스크롤 정지에만 쓰인다. 그 다음 그룹 순환에서 종료를 선택한다.
- 팝업이 오류를 보이거나 종료가 안 되면 브라우저 확장 관리에서 도우미를 끄고 사용하던 페이지를 새로고침한다. 주소창·브라우저 메뉴·다른 프로그램까지 이어지는 전역 Space 정지는 제공하지 않는다.

## 검증 범위

클라우드에서 실제 production 확장 설치, 네이티브 팝업의 Space 시작·정지, 일반 HTTPS 페이지의 활동 선택, 꺼진 뒤 문자/Space/마우스 클릭 복구, 늦은 응답의 자동 재개 방지, Chrome 확장 관리 비활성화를 확인했다. 공개 두산아트센터 사이트는 클라우드 네트워크 오류로 접속하지 못해 미검증이다. 실제 Windows 한국어 IME·운동 사용성·모든 사이트 지원을 이 결과로 보장하지 않는다. 이 안내는 사용자에게 즉시 추가 사용 시험을 요구하지 않는다.
