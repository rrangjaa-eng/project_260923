# Feature Research

**Domain:** 운동 장애(손 떨림) 이용자를 위한 브라우저 조작 보조 + 업무 양식 자동화
**Researched:** 2026-09-23
**Confidence:** MEDIUM (기능 목록은 승인된 설계에서 옴 — HIGH. 비교 제품 특성은 일반 지식 — MEDIUM)

## Feature Landscape

### Table Stakes (이용자가 당연히 기대하는 것)

이 이용자에게 "빠지면 쓰지 않는다" 수준인 것들. 모두 설계에 이미 있다.

| Feature | Why Expected | Complexity | Notes |
|---------|--------------|------------|-------|
| 누를 수 있는 요소 수집(모든 프레임) | 모든 클릭 보조의 바탕 | HIGH | iframe 보고·통합, MutationObserver 모아서 갱신, 보이는 요소만 |
| 떨림 걸러내기(재입력 무시, 자동 반복 끔, 더블클릭 축소) | Steady Clicks류 도구의 기본 | MEDIUM | 간격은 맞춤 설정·중간 이용자 시험으로 맞춘다 |
| 번호표(1~9) | Vimium류 링크 힌트의 기본 | MEDIUM | 입력칸 안에서는 키를 원래대로 |
| 자석 커서(가장 가까운 요소 잡기 + 히스테리시스) | 이 이용자의 기본 조작 방식 | HIGH | 50ms 반응 목표, 빈 곳 클릭은 그대로 |
| 입력 모드 표시("입력 중 / 도우미") | 키 충돌로 헷갈리지 않게 | LOW | contenteditable도 입력칸으로 |
| 도우미 끄기(전체·사이트별) | 방해될 때 즉시 빠져나올 길 | LOW | 첫 단계부터 있어야 한다(설계 10-1 ①) |
| 키 스크롤, Esc 되돌리기 | 마우스 없이 이동 | LOW | 스크롤 영역 여러 개면 자석 커서가 있는 영역 |
| 확인 화면 보호 | 떨림으로 되돌릴 수 없는 일 방지 | MEDIUM | 1초 입력 무시, Enter/스페이스바 1초로만 확인 |
| 위험한 버튼 보호 | 삭제·반려 등 오조작 방지 | MEDIUM | 끌어당기지 않음, 머무르기 안 됨, 번호로 고르면 재확인 |

### Differentiators (이 제품만의 것)

| Feature | Value Proposition | Complexity | Notes |
|---------|-------------------|------------|-------|
| 틀 자동화 + 제출 안전장치 | 반복 업무 한 건을 "틀 1 + 값 2~3 + 확인 1"로 | HIGH | Automa류 기록기에 제출 확인·재제출 금지·알림 창 처리를 더함 |
| 요소 찾기 점수(AI 없음) | 예측 가능, 확실하지 않으면 멈춤 | HIGH | id/name/라벨/버튼 글자/aria/경로 + 프레임 경로 |
| 양식 한 장 보기 | 작은 칸이 흩어진 회사 양식을 큰 칸 한 줄씩으로 | MEDIUM | 입력 이벤트를 함께 발생시켜 사이트가 알아채게 |
| 입력 줄이기 | 최근 값·자주 쓰는 문구를 번호로 | MEDIUM | 민감칸 제외 |
| 컨디션 모드 + 맞춤 설정 | 좋은 날/힘든 날을 한 번에 | LOW | 설정 묶음 전환 |
| 작업판 + 뒤에서 실행 + 확인 대기 | 틀을 뒤에서 돌리고 다른 일 계속 | HIGH | 뒤쪽 탭 속도 제한 확인 필요(설계 11장 ③) |
| 반복 패턴 알림 | 틀을 만들 때를 알려 줌 | MEDIUM | 3번 이상, 거절하면 다시 안 물음 |
| 화면 정리(AI) | 처음 보는 화면에서 중요한 9개 | MEDIUM | 키를 누를 때만, 답 검사, 한도, 키 없으면 이 기능만 꺼짐 |
| 활동 기록 + 주간 통계 | 문제 추적과 "실제로 나아지는가" 측정 | MEDIUM | 입력 값 제외, 2주, 내보내기 전 확인 |
| 민감칸 사이트별 풀기 | 업무 칸이 과하게 막히지 않게 | MEDIUM | 비밀번호 칸은 "암호화 없이 저장" 경고 |

### Anti-Features (일부러 만들지 않는 것)

| Feature | Why Requested | Why Problematic | Alternative |
|---------|---------------|-----------------|-------------|
| 보안 키패드 대신 누르기·자동입력 방지 문자 풀기 | 입력이 힘드니까 | 보안 우회, 사이트 약관 위반 | 만나면 멈추고 이용자가 직접 |
| 사이트에 요청 직접 보내기(화면 우회) | 빠르니까 | 사이트 입력 검사를 건너뜀, 데이터 손상 위험 | 화면을 거쳐 최대 속도 실행 |
| AI가 직접 누르기·AI 틀 복구 | 편하니까 | 되돌릴 수 없는 오조작 | AI는 번호만, 막히면 "이 단계만 다시 기록" |
| 제출 자동 재시도 | 실패하면 다시 | 중복 상신·중복 등록 | "확인 필요"로 두고 이용자가 확인 |
| 결재·상신을 위험 버튼 단어에 추가 | 외부 검토 제안 | 이용자가 거절(업무 흐름이 느려짐) | 제출 단계 확인으로 충분 |
| 서버 동기화·클라우드 백업 | 여러 PC | 운영 부담, 개인정보 | 브라우저 계정 동기화 + 파일 |

## Feature Dependencies

```
요소 수집기
    ├──> 자석 커서 ──> 머무르기 클릭
    ├──> 번호표 ──> 자동 순서 강조
    │         └──> 화면 정리(AI) (번호표를 붙이는 또 다른 출처)
    ├──> 양식 한 장 보기
    └──> 틀 기록기/요소 찾기 ──> 틀 실행 ──> 제출 확인·알림 창 처리
                                      └──> 뒤에서 실행 ──> 작업판 확인 대기
떨림 걸러내기 ──> (모든 입력 기능 앞단)
확인 화면 보호 ──> 위험 버튼 재확인, 제출 확인
민감칸 판별 ──> 입력 줄이기, 틀 저장, 활동 기록, AI 전송
명령판 ──> 컨디션 모드, 입력 되돌리기, 틀 실행/기록, 작업판, 화면 정리
저장소(sync/local/session, 형식 버전) ──> 거의 모든 것
활동 기록 ──> 틀 실행 중 잠듦 복구(제출 여부 확인), 주간 통계
```

### Dependency Notes

- **모든 클릭 기능은 요소 수집기와 떨림 걸러내기 위에 선다:** 그래서 설계 10-1 ①이 이 둘을 먼저 만든다.
- **확인 화면 보호는 Phase 1부터 필요하다:** 위험 버튼을 번호표로 고르는 재확인이 첫 단계에 들어가기 때문.
- **민감칸 판별은 입력 줄이기(③) 전에 있어야 한다:** 최근 값 기록이 민감칸을 건너뛰어야 하므로 ③에서 판별기를 먼저 만든다.
- **활동 기록은 틀 실행(④)과 함께:** 잠듦 복구가 "제출이 남았는지"를 활동 기록에서 보기 때문.
- **작업판(⑤)은 뒤에서 실행과 확인 대기의 화면:** 틀 실행이 먼저 있어야 한다.
- **화면 정리(⑥)는 번호표·요소 수집기만 있으면 되지만 가장 뒤:** 선택 기능이고 외부 전송·비용이 있어 마지막.

## MVP Definition

### Launch With (v1 — 이번 마일스톤)

설계 3장의 첫 버전 전체. 순서는 설계 10-1을 따른다.

- [ ] 클릭 도우미 묶음 + 떨림 걸러내기 + 도우미 끄기 — 핵심 가치
- [ ] 중간 이용자 시험과 기본값 조정 — 이후 모든 기본값의 근거
- [ ] 이동·입력 묶음 + 컨디션 모드 + 맞춤 설정
- [ ] 틀 자동화 + 활동 기록
- [ ] 작업판 + 뒤에서 실행 + 반복 패턴 알림
- [ ] 화면 정리(AI)

### Add After Validation (v1.x)

- [ ] 이용자 시험 결과에 따른 기본값·키 배치 재조정
- [ ] 사이트별 위험 버튼·민감칸 목록 기본값 확장

### Future Consideration (v2+)

- [ ] 윈도우 상주 프로그램(커서 떨림 완화, 웹 밖 머무르기·번호표)
- [ ] 엑셀·다른 사이트 정보 옮기기, 여러 건 입력
- [ ] 안드로이드 도우미, 아이폰
- [ ] AI 글 써 주기, AI 틀 복구

## Competitor Feature Analysis

| Feature | Vimium류 | Automa류 | Steady Clicks류 | 이 제품 |
|---------|----------|----------|-----------------|---------|
| 링크 힌트 | 글자 조합 힌트 | 없음 | 없음 | 1~9 숫자만, 자주 누른 순서·고정 번호 |
| 클릭 필터 | 없음 | 없음 | 있음 | 키보드·마우스 공통 + 확인 화면 보호 |
| 기록·재생 | 없음 | 노드 기반 워크플로 | 없음 | 한 번 해 보이기로 기록, 바뀌는 값 자동 표시 |
| 제출 안전 | 없음 | 없음 | 없음 | 항상 확인, 재시도 없음, 알림 창 처리 |
| 한 이용자 맞춤 | 없음 | 없음 | 부분 | 맞춤 설정·컨디션 모드 |
