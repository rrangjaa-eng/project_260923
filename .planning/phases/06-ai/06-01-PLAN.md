## Phase Goal

**As a** 이용자, **I want to** 처음 보는 복잡한 화면에서 명령판의 "화면 정리"를 누르면 중요한 요소 9개에 번호가 붙기를, **so that** AI가 없거나 실패해도 나머지 기능은 그대로이고, 개인정보와 입력 값은 밖으로 나가지 않는다.

(ROADMAP Phase 6 **Goal** 문장을 그대로 세 칸에 옮긴 것이다. 새 내용은 더하지 않았다. Goal 문장이 user story 형식이 아니라 so that 칸에 이득 대신 제약이 들어갔다 — `/gsd-mvp-phase 6`으로 다듬을 수 있다.)

<objective>
실행 첫 단계에서 `@anthropic-ai/sdk` 설치 승인을 받고(D-25), 화면 정리의 한 경로(tracer)를 끝까지 잇는다: 명령판 카드 → 맨 위 프레임이 모은 요소 목록(iframe 포함) → service worker의 AI 창구 → 가짜 Anthropic → 답 검사 → 1~9 번호표 + "AI가 고른 번호". 키가 없으면 AI를 부르지 않고 자주 누른 순서로 대신한다. 이어서 설계 10장이 명시한 "AI 답 검사" 단위 시험 행렬을 채운다.

## 실행 규칙 (모든 작업 공통)

- 패키지 매니저는 pnpm만. TypeScript strict, `any` 금지, 시크릿을 코드·커밋에 넣지 않는다(CLAUDE.md).
- 구현 전에 Superpowers `test-driven-development` 스킬을, 시험 실패·버그를 쫓기 전에 `systematic-debugging`을, "완료"라고 말하기 전에 `verification-before-completion`을 **호출**한다. 서브에이전트에 맡기면 그 프롬프트에 세 스킬과 `model`을 적는다(점검·판단은 Opus 5).
- `tdd="true"`/`type="tracer"` 작업은 실패하는 시험을 먼저 쓰고 실패를 확인한 뒤(RED 커밋 `test(06-01): …`) 최소 구현으로 통과시킨다(GREEN 커밋 `feat(06-01): …`). 커밋 제목은 영어 접두어, 본문은 한국어.
- 완료 판정은 `CI=true`로 돌린 e2e(프로덕션 빌드)다. 로컬 dev 통과는 완료 신호가 아니다.
- Task 1에서 승인받지 않은 패키지·권한은 더하지 않는다. `host_permissions: ['<all_urls>']`가 이미 API 주소를 덮으므로 새 권한은 없다(D-26). 필요해지면 멈추고 이유 한 줄과 함께 승인을 요청한다.
- **자동 시험은 진짜 Anthropic API를 부르지 않는다.** 시험 키는 `FAKE_AI_KEY`(진짜 키 모양이 아닌 문자열) 하나뿐이다. 진짜 키를 저장소·CI·환경변수 파일에 두지 않는다(D-28).
- 실제 회사 시스템에 접속하거나 시험하지 않는다(D-29).

## 가정 (spec-less edge probe)

이 phase에는 SPEC의 `## Edge Coverage`/`## Prohibitions`가 없어 plan-phase가 edge probe를 돌렸다. 요구사항 6개 모두 `unclassified — review manually`로 나와 자동 해결되지 않았다. 규칙대로 조용히 버리지 않고 각 요구사항의 주 계획에 표시한다.

- AI-01 (주 계획): edge probe `unclassified — review manually`. 가정: "중요한 요소 9개"는 AI가 1~9개를 고르는 것으로 본다 — 화면에 요소가 9개보다 적거나 AI가 9개 미만을 고르면 고른 만큼 AI 순서로 번호를 붙이고 남은 번호는 Phase 1 순서(고정 → 자주 누름 → 커서 근처)로 채운다. 요소가 9개 이하인 화면에서도 AI를 부른다(06-CONTEXT discretion — 이용자가 키를 눌렀으므로). "같은 페이지 다시 열면 저장된 번호" 경계는 06-03이 맡는다.
- AI-06 (일부 — 답 검사): 가정: "목록에 없는 요소"는 보낸 임시 번호가 아닌 값으로 판정하고, 하나라도 있으면 전체를 버린다. 형식 틀림·거절·잘림도 같은 대체로 본다. 오류 종류별 대체와 "직접 눌리지 않음"은 06-04가 맡는다.
- AI-05 (일부 — 키 없음 대체): 가정: 설정이 없거나 읽을 수 없거나 키 칸이 비면 모두 "키 없음"이다. 키 저장·동기화 금지는 06-05가 맡는다.
