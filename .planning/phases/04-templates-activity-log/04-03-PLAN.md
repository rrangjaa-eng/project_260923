## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 반복 업무를 한 번 해 보여 틀로 저장하고 이후 "틀 고르기 1번 + 바뀌는 값 2~3번 + 제출 확인 1번"으로 끝내기를, **so that** 되돌릴 수 없는 제출은 항상 확인 뒤에 한 번만 일어나고 문제가 생기면 활동 기록으로 추적할 수 있다.

<objective>
이용자가 명령판에서 "틀 기록"을 켜고 연습 업무 흐름(메뉴 → 양식 → 상신)을 한 번 한 뒤 같은 자리로 끝내면 틀이 저장되는 첫 세로 조각. 모든 층(content script 기록기 → 메시지 → SW 라우터 → 단일 저장자 → 저장 형식 → 모드 표시)을 한 경로로 잇는다.

Purpose: TMPL-01(D-06~D-10)의 뼈대. 이 계획의 저장 형식(`templates`, `record-session`)과 메시지 경로(`TEMPLATE_MESSAGE_TYPES` → 라우터)를 뒤 모든 계획과 Phase 5가 쓴다. 이름 고르기 화면·기록 합치기 규칙·iframe 경로는 04-04.
Output: 저장 형식, Phase 4 메시지 묶음, SW 라우터, 기록기, 틀 조정기(기록 명령), 모드 표시 활동 글자, e2e.
</objective>
