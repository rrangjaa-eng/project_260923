## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 반복 업무를 한 번 해 보여 틀로 저장하고 이후 "틀 고르기 1번 + 바뀌는 값 2~3번 + 제출 확인 1번"으로 끝내기를, **so that** 되돌릴 수 없는 제출은 항상 확인 뒤에 한 번만 일어나고 문제가 생기면 활동 기록으로 추적할 수 있다.

<objective>
저장한 틀을 고르고, 바뀌는 값을 번호로 고르고, 시작 페이지로 곧장 가서 단계를 자동으로 실행한 뒤 제출 직전 요약 확인 화면에서 멈추는 세로 조각을 만든다. 실행 조정은 service worker(단일 상태 기계, storage.session), 페이지는 "이 프레임에서 이 단계 하기"만 한다.

Purpose: TMPL-04(D-14), TMPL-06(D-16, D-17), TMPL-05의 확신 판정 첫 모양(D-15). 제출 누르기와 결과 판정은 04-05, 막힘 카드는 04-06.
Output: 실행 상태 형식, 확신 판정·값 후보·문구 순수 함수 + 단위 시험, 오케스트레이터, 단계 실행기, 틀 목록·바뀌는 값 카드, 프레임 라우팅, e2e.
</objective>
