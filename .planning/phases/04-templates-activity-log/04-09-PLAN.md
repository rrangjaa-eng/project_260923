## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 반복 업무를 한 번 해 보여 틀로 저장하고 이후 "틀 고르기 1번 + 바뀌는 값 2~3번 + 제출 확인 1번"으로 끝내기를, **so that** 되돌릴 수 없는 제출은 항상 확인 뒤에 한 번만 일어나고 문제가 생기면 활동 기록으로 추적할 수 있다.

<objective>
제출 확인 화면의 Enter 한 번 → 누름 기록을 먼저 저장 → 제출 버튼을 정확히 한 번 누름 → 페이지 이동·새 문서로 성공 → "상신했어요" 알림 + 활동 기록 한 줄.

Purpose: TMPL-09(D-22), TMPL-10의 앞부분(D-23), LOG-01의 첫 기록(D-32·D-33). 활동 기록 입구 `logActivity`와 제출 확인 `confirmSubmit`은 뒤 계획과 Phase 5가 그대로 쓴다. 성공 글자·기한·중간 제출·위험 단계 확인은 04-10.
Output: 누름 기록·활동 기록 형식 + 단위 시험, `logActivity`, 제출 파이프라인, 성공 알림 색, e2e.
</objective>
