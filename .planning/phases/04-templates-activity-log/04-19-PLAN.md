## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 반복 업무를 한 번 해 보여 틀로 저장하고 이후 "틀 고르기 1번 + 바뀌는 값 2~3번 + 제출 확인 1번"으로 끝내기를, **so that** 되돌릴 수 없는 제출은 항상 확인 뒤에 한 번만 일어나고 문제가 생기면 활동 기록으로 추적할 수 있다.

<objective>
민감한 칸에서는 멈추고 이용자가 직접 입력하게 한다(값은 어디에도 남지 않음). "직접 하기" 흐름(카드·키·이어 가기)을 만들어 04-20의 키패드·자동입력 방지 문자·결제 화면이 같은 흐름을 쓰게 한다.

Purpose: TMPL-14(D-29, D-10, D-21, D-22). 직접 하기 상태(`awaiting-manual` + `manualReason`, `requiresTabAction`)는 Phase 5 작업판이 "이 탭에서 직접 해야 함"을 보여 주는 자리다.
Output: 직접 하기 카드(SYSTEM.md 템플릿 먼저), 'awaiting-manual' 흐름, `manualCardText` + 단위 시험, `requiresTabAction` + 단위 시험, 실행 때 민감 재판별, e2e.
</objective>
