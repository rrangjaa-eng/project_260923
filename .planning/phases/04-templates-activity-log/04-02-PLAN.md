## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 반복 업무를 한 번 해 보여 틀로 저장하고 이후 "틀 고르기 1번 + 바뀌는 값 2~3번 + 제출 확인 1번"으로 끝내기를, **so that** 되돌릴 수 없는 제출은 항상 확인 뒤에 한 번만 일어나고 문제가 생기면 활동 기록으로 추적할 수 있다.

<objective>
이용자가 명령판에서 "틀 기록"을 켜고 연습 사이트의 업무 흐름(메뉴 → 양식 → 상신)을 한 번 한 뒤 "기록 끝내기"로 틀을 저장하는 첫 세로 조각을 만든다. 모든 층(연습 페이지 → content script 기록기 → 메시지 → SW 라우터 → 단일 저장자 → 저장 형식 → 오버레이)을 한 경로로 잇는다.

Purpose: TMPL-01(D-06~D-10). 이 계획의 저장 형식(`templates`, `record-session`)을 이후 모든 계획이 쓴다.
Output: 저장 형식·기록 합성 순수 함수 + 단위 시험, Phase 4 메시지 묶음, SW 라우터, 기록기, 틀 저장 화면(이름 단계), 연습 사이트 업무 흐름 4쪽, e2e.
</objective>
