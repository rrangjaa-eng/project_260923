## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 반복 업무를 한 번 해 보여 틀로 저장하고 이후 "틀 고르기 1번 + 바뀌는 값 2~3번 + 제출 확인 1번"으로 끝내기를, **so that** 되돌릴 수 없는 제출은 항상 확인 뒤에 한 번만 일어나고 문제가 생기면 활동 기록으로 추적할 수 있다.

<objective>
service worker가 실행 도중 잠들었다 깨어나도 저장된 상태에서 이어 가고, 누름만 있고 결과가 없는 제출은 다시 누르지 않고 '확인 필요'로 둔다. 같은 틀 두 번 실행을 막고, 틀이 도는 동안 확장 업데이트를 미룬다.

Purpose: TMPL-13(D-24), TMPL-07(D-18), D-25. 실행 기록은 탭에 매이지 않은 run-index로 찾는다(D-17 — Phase 5가 그대로 쓴다).
Output: 재개·잠금·업데이트·정리 순수 규칙 + 단위 시험, `resumeAll`, `relay.refreshTab`, 잠금 안내, 업데이트 미루기, e2e(SW 강제 종료).
</objective>
