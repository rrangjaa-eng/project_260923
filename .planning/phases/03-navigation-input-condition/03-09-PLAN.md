## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 마우스 없이 명령판과 키로 이동·되돌리기를 하고, 긴 입력 양식을 큰 칸 화면과 최근 값·문구 카드로 채우며, 그날 손 상태에 맞는 설정 묶음을 한 번에 고르기를, **so that** 손 상태가 나쁜 날에도 잘못 누르거나 같은 값을 다시 치지 않고 평소 업무 사이트를 끝까지 쓸 수 있다.

Purpose: INPT-01, INPT-02(저장). 같은 값을 다시 치지 않는다. 문구 고치기·빼기는 설정 화면(03-13).

## 가정 (spec-less edge probe)

- INPT-01·INPT-02: edge probe `unclassified — review manually`. 가정한 경계:

  - 카드는 칸이 있는 프레임에 그린다(Claude's Discretion 6 — 맨 위로 보내면 칸 위치 변환과 왕복이 생긴다. 확인 화면·명령판처럼 "하나만 떠야 하는" 화면이 아니다).

  - 문구는 칸 이름별이다(INPT-01 "그 칸(사이트 + 칸 이름)의 … 자주 쓰는 문구"). 문구 고치기·빼기는 설정 화면(03-13).
