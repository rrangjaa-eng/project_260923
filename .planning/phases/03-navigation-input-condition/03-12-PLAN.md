## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 마우스 없이 명령판과 키로 이동·되돌리기를 하고, 긴 입력 양식을 큰 칸 화면과 최근 값·문구 카드로 채우며, 그날 손 상태에 맞는 설정 묶음을 한 번에 고르기를, **so that** 손 상태가 나쁜 날에도 잘못 누르거나 같은 값을 다시 치지 않고 평소 업무 사이트를 끝까지 쓸 수 있다.

<objective>
SYSTEM.md에 없는 두 화면(설정 화면, 처음 설치 맞춤 설정)의 템플릿을 먼저 더하고(D-38, DESIGN.md §4-1), 확장 옵션 페이지로 설정 화면의 틀과 "키 배치" 절을 만든다(D-32).

Purpose: PERS-03. 이후 03-13(나머지 설정 절)·03-14(설정 파일)·03-15(맞춤 설정)가 이 틀에 절을 붙인다.
Output: SYSTEM.md 템플릿 둘 + DECISIONS.md 기록, 옵션 페이지와 공통 틀, 키 배치 절, 확장 아이콘 메뉴 카드 5, `setKeymap`, `options.e2e.ts`.
</objective>
