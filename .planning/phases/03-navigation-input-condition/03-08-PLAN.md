## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 마우스 없이 명령판과 키로 이동·되돌리기를 하고, 긴 입력 양식을 큰 칸 화면과 최근 값·문구 카드로 채우며, 그날 손 상태에 맞는 설정 묶음을 한 번에 고르기를, **so that** 손 상태가 나쁜 날에도 잘못 누르거나 같은 값을 다시 치지 않고 평소 업무 사이트를 끝까지 쓸 수 있다.

## 가정 (spec-less edge probe)

- PRIV-01·INPT-01: edge probe `unclassified — review manually`. 가정한 경계:
  - 모양 규칙(Claude's Discretion 5): 주민번호 = 숫자 6 + 하이픈 선택 + 숫자 7. 계좌번호 = 숫자·하이픈·공백만, 숫자 10~16자리. 카드번호 = 숫자 14~16자리 + Luhn. 모양 단어가 없는 칸("비고")에 번호 모양 값이 들어가도 민감으로 보지 않는다(설계 8장 문장 그대로).
  - 단어는 이름·id·라벨·aria·placeholder를 이어 붙인 글자에서 찾는다(띄어쓰기·대소문자 무시). 영어 이름 "passwd"처럼 목록 단어가 들어 있지 않은 칸은 `type=password`가 아니면 잡히지 않는다 — 이용자가 설정에서 단어를 더한다(PRIV-03, 03-13).
  - 최근 값은 벗어날 때(focusout) 값이 바뀌었을 때만 기록한다(Claude's Discretion 4 — "바뀜·벗어남·제출" 중 벗어남). 도우미가 카드·양식 한 장 보기로 채운 값은 03-09·03-11이 같은 규칙으로 기록한다.
  - "사이트"는 맨 위 출처다 — iframe 안 칸도 맨 위 사이트의 최근 값에 들어간다.
  - 칸 이름이 없는 칸(`fieldKey` null)은 기록하지 않는다.
  - 칸 이름은 `name` → `id` → 라벨 → aria → placeholder 순서다. 페이지마다 새로 만드는 id(자동 생성 id)는 칸 구분이 흔들릴 수 있다 — 연습 사이트 밖(회사 시스템) 확인은 회사 시스템 완성 뒤.
