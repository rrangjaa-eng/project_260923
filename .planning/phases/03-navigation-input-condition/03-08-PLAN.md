## 가정 (spec-less edge probe)

- NAV-03: edge probe `unclassified — review manually`. 가정한 경계:
  - "직후" = 도우미가 링크를 누른 뒤 10초 안에 새 문서가 시작되었고, 새 문서에서 처음 누르는 키가 Esc이며, 새 문서 시작 뒤 10초 안(RESEARCH 권장 "새 문서의 첫 Esc" + 느린 회사 시스템을 위한 시간 여유). 첫 마우스 누름도 무장을 푼다.
  - 뒤로 가기 대상은 맨 위 프레임의 같은 탭 링크(`target` 없음·`_self`·`_top`)뿐이다. iframe 안에서만 바뀌는 링크, 주소만 바꾸는 한 페이지 앱(history.pushState), 새 탭 링크는 대상이 아니다.
  - Esc 우선순위: 확인 화면 > 명령판 > 양식 한 장 보기 > 입력 중 > 끌기 시작 > 번호표 > 자동 순서 강조 > 링크 직후 뒤로 > 사이트로 통과(RESEARCH Pattern 3 + 이 phase의 새 상태).
  - SW가 쉬었다 깨도 세션 저장소 기록은 남는다(브라우저를 다시 켜면 사라짐 — 10초 기록이라 문제 없음, RESEARCH Pitfall 2).
