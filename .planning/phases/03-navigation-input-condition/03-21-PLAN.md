## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 마우스 없이 명령판과 키로 이동·되돌리기를 하고, 긴 입력 양식을 큰 칸 화면과 최근 값·문구 카드로 채우며, 그날 손 상태에 맞는 설정 묶음을 한 번에 고르기를, **so that** 손 상태가 나쁜 날에도 잘못 누르거나 같은 값을 다시 치지 않고 평소 업무 사이트를 끝까지 쓸 수 있다.

<objective>
설정 파일 형식(D-34, D-35)을 순수 함수로 먼저 고정한다 — 만들기·읽기·덮어쓰기 계획·파일 이름. 설정 화면의 내보내기·가져오기와 동기화 용량 알림은 03-22가 이 함수 위에 붙인다.

Purpose: STOR-04 — 크롬↔엣지↔웨일 사이 옮기기(계정 동기화는 같은 브라우저끼리만). 파일을 다른 계획과 나누지 않는 순수 계획이라 설정 v2(03-03) 뒤 곧바로 나란히(wave 4) 돈다.
Output: `settings-file.ts`+단위 시험.
</objective>
