## 가정 (spec-less edge probe)

- PERS-02: edge probe `unclassified — review manually`. 가정한 경계(Claude's Discretion 8):
  - 떨림 간격 = 한 번 누른 뒤 1.5초 안에 들어온 같은 키 다시 눌림 간격의 90% 값 + 50ms(150~1000ms). 다시 눌림이 한 번도 없으면 기본값을 그대로 쓴다(재기로 값을 낮추지 않는다 — 걸러낼 것이 없다는 뜻이 아니라 표본이 없다는 뜻이라서).

  - 힘든 날 = 잰 값 ×1.5. 두 묶음의 조작 방식·강조 속도·표시 크기는 바꾸지 않는다.
