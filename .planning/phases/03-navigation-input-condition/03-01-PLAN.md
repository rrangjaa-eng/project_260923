## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 마우스 없이 명령판과 키로 이동·되돌리기를 하고, 긴 입력 양식을 큰 칸 화면과 최근 값·문구 카드로 채우며, 그날 손 상태에 맞는 설정 묶음을 한 번에 고르기를, **so that** 손 상태가 나쁜 날에도 잘못 누르거나 같은 값을 다시 치지 않고 평소 업무 사이트를 끝까지 쓸 수 있다.

<objective>
실행 전 전제(Phase 1 계획 13~16·Phase 2 완료, 가정한 API 존재)를 확인한 뒤, 0 → 명령판 → "7 새로고침" 한 경로를 끝까지 이어 구조를 증명하고(tracer), 세 장의 고정 카드 자리·탭 명령·키 안내 카드·"준비 중" 카드로 넓힌다.

Purpose: NAV-02(D-05, D-06, D-07). 명령판은 이후 모든 Phase 3 계획(되돌리기·번호 고정·더블클릭·양식 한 장 보기·민감칸 설정·컨디션·맞춤 설정)이 명령을 붙이는 입구다.
Output: 전제 확인 기록, `palette-slots.ts`+단위 시험, 명령판 컨트롤러·화면, `tab/command` 메시지와 SW 처리, 모드 표시 문구, `palette.e2e.ts`.
</objective>
