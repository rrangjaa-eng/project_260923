## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 마우스 없이 명령판과 키로 이동·되돌리기를 하고, 긴 입력 양식을 큰 칸 화면과 최근 값·문구 카드로 채우며, 그날 손 상태에 맞는 설정 묶음을 한 번에 고르기를, **so that** 손 상태가 나쁜 날에도 잘못 누르거나 같은 값을 다시 치지 않고 평소 업무 사이트를 끝까지 쓸 수 있다.

Purpose: CLICK-05. 손이 특히 힘든 날 커서를 움직이지 않고 키 하나로 누른다. 위험한 버튼은 번호표와 같은 확인 화면(D-15).
Output: `auto-hint-cycle.ts`+단위 시험, content의 방식 분기와 강조 루프, `auto-cycle.e2e.ts`.
</objective>

## 가정 (spec-less edge probe)

- CLICK-05: edge probe `unclassified — review manually`. 가정한 경계:
  - "아무 키(기본 스페이스바)"는 키 배치의 '누르기' 키 하나로 읽었다(설계 5장 키 표: "스페이스바 = 자동 순서 강조에서 선택"). Esc·0·숫자는 원래 뜻을 지킨다 — 모든 키를 선택으로 쓰면 떨림으로 잘못 눌린 키가 선택이 된다.
  - 강조는 스페이스바로 시작한다(페이지를 열자마자 저절로 돌지 않는다). 시작 한 번 + 선택 한 번, 두 번 누른다.
  - 아무것도 고르지 않으면 세 바퀴 뒤 멈춘다(끝없이 도는 강조가 화면을 계속 움직이지 않게). 값은 코드 기본값 3.
  - 강조 속도는 컨디션 묶음의 `autoCycleMs`(500~5000ms)로만 바꾼다. 강조 중 ←→로 바꾸는 기능은 없다(←→는 Phase 4 틀 실행 속도).
  - 번호표 방식에서는 머무르기(dwell)도 쉰다 — 머무르기는 자석 커서가 잡은 요소가 있어야 한다.
