## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 마우스 없이 명령판과 키로 이동·되돌리기를 하고, 긴 입력 양식을 큰 칸 화면과 최근 값·문구 카드로 채우며, 그날 손 상태에 맞는 설정 묶음을 한 번에 고르기를, **so that** 손 상태가 나쁜 날에도 잘못 누르거나 같은 값을 다시 치지 않고 평소 업무 사이트를 끝까지 쓸 수 있다.

<objective>
설정 파일 내보내기·가져오기(D-34, D-35)와 동기화 용량 알림(D-33)을 만든다. 파일 저장은 새 권한 없이 옵션 페이지의 Blob + `a[download]`로 한다(03-RESEARCH Pattern 8 — SW에서는 안 된다).

Purpose: STOR-04 — 크롬↔엣지↔웨일 사이 옮기기(계정 동기화는 같은 브라우저끼리만). STOR-03 — 용량을 넘기 전에 알리고 문구부터 파일로 내보내게 안내.
Output: `settings-file.ts`+단위 시험, 설정 파일 절, `importSettingsFile`, 용량 검사·알림, 메뉴 경고 카드, e2e 두 파일.
</objective>
