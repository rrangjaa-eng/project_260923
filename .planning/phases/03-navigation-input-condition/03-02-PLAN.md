## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 마우스 없이 명령판과 키로 이동·되돌리기를 하고, 긴 입력 양식을 큰 칸 화면과 최근 값·문구 카드로 채우며, 그날 손 상태에 맞는 설정 묶음을 한 번에 고르기를, **so that** 손 상태가 나쁜 날에도 잘못 누르거나 같은 값을 다시 치지 않고 평소 업무 사이트를 끝까지 쓸 수 있다.

<objective>
설정 저장 형식을 v2로 올린다: 컨디션 묶음 둘, 전체 키 배치, 명령판 카드 자리, 민감 판별 단어, 사이트 항목의 문구·민감칸 자리, 최근 입력 값 형식. v1 → v2 변환을 01-14의 `migrate()`에 처음으로 실제 변환으로 넣고, 모든 읽는 곳을 v2로 바꾼다.

Purpose: PERS-01(D-29 묶음 구조), PERS-03(D-32 키 배치 구조), D-03(형식 버전·변환 실패 보호), D-04(저장 위치). 이후 계획 전부가 이 형식을 읽는다.
Output: 형식 결정 승인, v2 스키마+변환+단위 시험, `keys.ts`+단위 시험, 읽는 곳 전환, `settings-v2.e2e.ts`.
</objective>
