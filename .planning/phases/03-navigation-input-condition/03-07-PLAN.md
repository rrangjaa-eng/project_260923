## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 마우스 없이 명령판과 키로 이동·되돌리기를 하고, 긴 입력 양식을 큰 칸 화면과 최근 값·문구 카드로 채우며, 그날 손 상태에 맞는 설정 묶음을 한 번에 고르기를, **so that** 손 상태가 나쁜 날에도 잘못 누르거나 같은 값을 다시 치지 않고 평소 업무 사이트를 끝까지 쓸 수 있다.

<objective>
↑↓ 키 스크롤(D-08)을 만든다. 키 한 번이 키를 받은 프레임 → SW → 커서가 있는 프레임 → 스크롤 영역까지 끝까지 지나는 한 작업이다.

Purpose: NAV-01. 스크롤 영역 찾기는 커서가 있는 프레임에서 바로 하고, 프레임 사이 전달은 SW가 한다(D-01). "링크 이동 직후 Esc = 뒤로"(NAV-03)는 03-08이 같은 사슬 위에 붙인다.
Output: `scroll.ts`, 연습 페이지 둘, `cursor/here`·`scroll/key`·`scroll/request` 중계, `scroll.e2e.ts`.
</objective>
