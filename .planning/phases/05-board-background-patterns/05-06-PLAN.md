## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 탭·자주 가는 곳·뒤에서 도는 틀의 진행 상황·확인 대기를 작업판 한 곳에서 번호로 처리하고 틀로 만들 만한 반복을 도우미가 알려 주기를, **so that** 틀을 뒤쪽 탭에서 돌리는 동안 다른 탭에서 계속 일할 수 있다.

<objective>
확인 대기의 두 번째 경로(제출 확인)를 꿴다: 뒤에서 도는 틀이 제출 직전에 멈추면 → 확인 대기에 쌓이고 → 이용자가 지금 탭 위의 확인 화면에서 보호 시간 뒤 Enter(또는 스페이스바 1초)로 확인하면 → service worker가 확인한 뒤 실행 탭에 한 번 넘기고 → 실행 탭의 Phase 4 실행기가 "누름" 기록을 남기고 한 번 누른다. 이어서 두 번 처리·전달 실패·탭 닫힘·취소를 막고, 도울 수 없는 탭의 메뉴 경로와 iframe 초점 경로를 마친다.

Purpose: BORD-04 제출 확인(D-09), BG-01 확인 대기 처리(D-12), D-02(확인 화면 보호 그대로), D-25(다른 탭의 답을 실행 탭에 넘기는 길), D-27(활동 기록), discretion "지금 탭 위에서 처리, 실제 누르기는 실행 탭 — Phase 4의 누르기 직전 '누름' 기록 재사용, 제출은 한 번, 다시 시도 없음".
Output: `openSubmitConfirm`, 확인 모달 통로 등록, 전달 실패 결과 `'not-delivered'`, `runner-bridge.test.ts`, 메뉴 경로 `board/queue-open`, `queue-confirm.e2e.ts`.
</objective>
