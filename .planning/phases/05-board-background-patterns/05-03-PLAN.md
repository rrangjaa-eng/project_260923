## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 탭·자주 가는 곳·뒤에서 도는 틀의 진행 상황·확인 대기를 작업판 한 곳에서 번호로 처리하고 틀로 만들 만한 반복을 도우미가 알려 주기를, **so that** 틀을 뒤쪽 탭에서 돌리는 동안 다른 탭에서 계속 일할 수 있다.

<objective>
자주 가는 곳을 한 경로로 먼저 꿴다(고정 → 동기화 저장 → 작업판 목록 → 번호로 이동). 이어서 떨림에 안전한 "0 → 번호 → 확인" 흐름으로 탭 닫기와 고정 풀기를 만들고, 작업판을 여는 나머지 길(명령판 카드 2, 키 배치, 도울 수 없는 페이지의 확장 아이콘 메뉴)을 잇는다.

Purpose: BORD-02(D-07, D-04 sync, D-03 8KB), BORD-01 닫기·명령판 열기(D-05, D-06, D-02 확인 화면 보호), Claude's Discretion(닫기 오확인 방지, 도울 수 없는 페이지에서 여는 법, 자주 가는 곳 한도).
Output: `FavoritesV1`·writer op 둘, 작업판 자주 가는 곳 구획, 닫기·풀기 흐름, 명령판·키 배치·메뉴 연결, e2e 셋.
</objective>

## 가정 (spec-less edge probe)

- BORD-02: edge probe `unclassified — review manually`. 가정한 경계:
  - "자주 가는 곳" = 이용자가 고정한 페이지 주소(해시 제외, 쿼리 포함). 제목은 고정할 때의 탭 제목 40자. 24개·주소 512자·한 동기화 항목 8KB 한도.
  - 여는 규칙: 해시를 뺀 주소가 같은 탭이 있으면 그 탭, 없으면 새 탭.
  - 다른 PC 적용은 자동 시험으로 할 수 없어 backstop(수동).
- BORD-01(닫기·여는 길):
  - 닫기·풀기 = 0 → 번호 → 확인 화면(1초 보호). 틀이 도는 탭의 경고 문구는 05-07에서 켠다(실행 상태 연결 뒤).
  - 도울 수 없는 페이지에서 키보드만으로 메뉴를 여는 브라우저 단축키(`chrome.commands`)는 넣지 않았다 — 메뉴는 확장 아이콘으로 연다(권한 없이 나중에 더할 수 있음). 수동 확인 목록에 남긴다.
