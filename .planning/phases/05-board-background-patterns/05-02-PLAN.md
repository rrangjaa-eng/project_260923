## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 탭·자주 가는 곳·뒤에서 도는 틀의 진행 상황·확인 대기를 작업판 한 곳에서 번호로 처리하고 틀로 만들 만한 반복을 도우미가 알려 주기를, **so that** 틀을 뒤쪽 탭에서 돌리는 동안 다른 탭에서 계속 일할 수 있다.

<objective>
작업판의 첫 수직 조각을 만든다: 도우미 모드에서 작업판 키를 누르면 → 맨 위 프레임이 service worker에 탭 목록을 물어 → 큰 번호 카드로 보여 주고 → 번호를 누르면 그 탭으로 이동한다. 그 전에 D-21대로 SYSTEM.md에 작업판 템플릿을 먼저 더한다(이 phase의 모든 화면 — 이후 계획은 SYSTEM.md를 다시 고치지 않는다). 이어서 장 넘기기·Esc·번호 고정·떨림 필터·다른 창·iframe 초점을 다듬는다.

Purpose: BORD-01 이동 부분(D-05, D-06), 화면 기준(D-20~D-23), 입력 규칙(D-02), 구조(D-01). 탭 **닫기**는 05-03(자주 가는 곳 풀기와 같은 "0 → 번호 → 확인" 흐름)이다. Task 1이 tracer 앞에 오는 이유: D-21이 "먼저 SYSTEM.md에 템플릿을 더한 뒤 만든다"를 잠근 결정으로 정했다.
Output: SYSTEM.md 작업판 템플릿, `board-model.ts`+단위 시험, `worker/board.ts`, 작업판 오버레이(`board.ts`, `board-view.ts`), `keymap.openBoard`, `board.e2e.ts`.
</objective>

- **구획 장:** 제목(구획 이름) + 번호 카드 1~9. 9개를 넘으면 1~8 + `9 다음 장`. 아래 줄 키 칩 버튼: 열린 탭 `[0 탭 닫기] [Esc 뒤로]`, 자주 가는 곳 `[0 고정 풀기] [Esc 뒤로]`, 그 밖 `[Esc 뒤로]`. Esc = 이전 장 → 첫 장 → 닫기.
- **탭 카드:** 큰 번호 + 탭 제목(한 줄, 넘치면 말줄임) + 사이트 이름(`--text-sm`, `--muted`). 작업판을 연 탭은 목록에 없다. 열려 있는 동안 번호는 고정 — 사라진 탭은 "닫힌 탭" 카드(`--muted` 글자)로 남는다.
- **자주 가는 곳:** 1 = 고정 자리 "지금 페이지 고정"(이미 고정했으면 "지금 페이지 고정 풀기"), 2~8 = 고정한 곳(이름 + 사이트), 9 = 다음 장.
- **"0 → 번호 → 확인" 흐름:** 0을 누르면 제목이 "닫을 탭 번호를 고르세요"(풀기는 "풀 곳 번호를 고르세요")로 바뀌고, 번호를 고르면 확인 화면 템플릿(확인 카드 radius 14, 남색 3px, 1초 보호 막대)으로 "이 탭을 닫을까요?" + 탭 제목 + `[Enter 닫기] [Esc 취소]`. 틀이 도는 탭이면 첫 줄에 "틀이 도는 탭이에요. 닫으면 틀이 멈춰요." 풀기는 "고정을 풀까요?" + `[Enter 풀기] [Esc 취소]`.
- **뒤에서 도는 틀 카드:** 틀 이름 + 단계 진행 막대(채움 `--accent`, 바탕 `--surface`, 높이 8px, radius 없음 또는 `--radius-key`) + "3/8 단계"(`tabular-nums`) + 상태 글자(도는 중 / 값을 기다려요 / 상신 확인을 기다려요). 막힘·확인 필요·멈춤 = `--warning` 테두리 카드 + 이유 한 문장(예: "뒤 탭이 닫혀 틀을 멈췄어요. 필요하면 틀을 다시 실행하세요.", "로그인이 풀려 틀을 멈췄어요. 다시 로그인한 뒤 틀을 다시 실행하세요.", "제출이 됐는지 알 수 없어요. 그 사이트에서 직접 확인하세요."). 멈춘 카드를 고르면 이유 + `[1 목록에서 치우기] [Esc 뒤로]`.
