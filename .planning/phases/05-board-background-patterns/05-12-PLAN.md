## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 탭·자주 가는 곳·뒤에서 도는 틀의 진행 상황·확인 대기를 작업판 한 곳에서 번호로 처리하고 틀로 만들 만한 반복을 도우미가 알려 주기를, **so that** 틀을 뒤쪽 탭에서 돌리는 동안 다른 탭에서 계속 일할 수 있다.

<objective>
뒤에서 도는 탭이 로그아웃되면 그 틀을 멈추고 작업판에 이유를 보인다(BG-02의 로그아웃 절반). 05-07이 만든 멈춤 경로(`stopRun`, `createRunStopWatcher`, 작업판 경고 카드·확인 대기·칩·배지 정리) 위에 신호 하나를 더한다. 먼저 한 경로를 꿴다: 실행 탭이 같은 사이트의 로그인 화면으로 넘어감 → 실행 탭 맨 위 프레임이 origin+경로와 참/거짓 신호를 보냄 → service worker가 판정 → `stopRun(runId, 'logged-out')` → 작업판에 이유. 이어서 판정 규칙 다섯 단계(다른 로그인 사이트, 페이지 안 로그인 창, 보통 이동, 알려지지 않은 사이트)를 단위 시험으로 굳힌다.

이 일은 원래 05-07의 Task 2였다. 05-07의 예상 비용(105000)이 smart-zone 예산(100000)을 넘어 떼어 냈다.

Purpose: BG-02 로그아웃 부분(D-14), D-11(실패 = 카드에 이유), D-27(멈춤 이유 활동 기록), D-28(로그인·로그아웃 흉내 페이지), 설계 9장(다시 누르지 않음), CONTEXT Claude's Discretion "로그아웃됨 판정 규칙 — 단위 시험으로 고정, 애매하면 멈추고 이유".
Output: `logout-heuristic.ts`(+단위), `run-watch.ts`, `session-app.html`·`login.html`, `run/for-tab`·`run/page-signal`, `run-stop.e2e.ts`에 로그아웃 e2e.
</objective>
