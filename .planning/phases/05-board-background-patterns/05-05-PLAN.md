## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 탭·자주 가는 곳·뒤에서 도는 틀의 진행 상황·확인 대기를 작업판 한 곳에서 번호로 처리하고 틀로 만들 만한 반복을 도우미가 알려 주기를, **so that** 틀을 뒤쪽 탭에서 돌리는 동안 다른 탭에서 계속 일할 수 있다.

<objective>
확인 대기의 첫 경로(값 고르기)를 꿴다: 뒤에서 도는 틀이 값을 기다리면 → 작업판 "확인 대기"에 쌓이고 → 이용자가 번호로 불러와 지금 탭 위에서 값을 고르면 → service worker가 확인한 뒤 실행 탭에 한 번 넘기고 → 틀이 이어 간다. 이어서 직접 입력·실패 경로·활동 기록, 5분 넘게 숨은 탭의 속도 측정을 마친다. 하던 일을 끊지 않는 알림("확인 대기 N" 칩·아이콘 배지)은 이 계획의 확인 대기 흐름 위에 05-13이 더한다(원래 이 계획의 Task 2 — files_modified 16개가 계획당 15개 미만 예산을 넘어 떼어 냈다).

Purpose: BG-01 "확인 대기에 쌓인다"(D-12), BORD-04 값 고르기(D-09), D-10(확인 창을 저절로 띄우지 않음 — 칩·배지는 05-13), D-25(다른 탭에서 처리한 답을 실행 탭에 넘기는 길), D-27(활동 기록), D-13(집중 스로틀링 구간 측정), discretion "지금 탭 위에서 처리, 실제 누르기는 실행 탭".
Output: `runner-bridge.ts`, `queue-screens.ts`(값 고르기), 확인 대기 구획, `queue.e2e.ts`, 긴 숨김 측정.
</objective>
