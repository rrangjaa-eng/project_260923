## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 탭·자주 가는 곳·뒤에서 도는 틀의 진행 상황·확인 대기를 작업판 한 곳에서 번호로 처리하고 틀로 만들 만한 반복을 도우미가 알려 주기를, **so that** 틀을 뒤쪽 탭에서 돌리는 동안 다른 탭에서 계속 일할 수 있다.

<objective>
확인 대기를 하던 일을 끊지 않고 알린다. 먼저 한 경로를 꿴다: 뒤에서 도는 틀이 값을 기다림 → service worker가 기다림 수를 셈 → 모든 탭 맨 위 프레임에 방송 → 모드 표시 오른쪽 "확인 대기 N" 칩 → 작업판으로 값을 넘기면 칩이 사라짐. 이어서 확장 아이콘의 같은 숫자 배지("도울 수 없음" 탭은 "없음" 우선)와 새로 연 탭의 칩을 마친다.

이 일은 원래 05-05의 Task 2였다. 05-05의 files_modified(16개)가 계획당 15개 미만 예산을 넘어 떼어 냈고, 05-05의 확인 대기 흐름(값 기다림 → 작업판 확인 대기 → `board/answer`) 위에 선다. 내용(행동·문구·시험)은 그대로이고, 새 계획의 첫 작업을 tracer로 두려고 칩 경로와 배지 경로를 두 작업으로 나눴다.

Purpose: D-10(확인 창을 바로 띄우지 않고 칩·배지로만 알림), BG-01 "확인 대기에 쌓인다"의 알림 부분(D-12), BORD-04, discretion "배지 숫자와 '도울 수 없음' 배지가 겹칠 때의 우선순위".
Output: `badge.ts`, `badge-text.ts`(+ 단위 시험), 모드 표시 칩 `setQueueCount`, 메시지 `board/queue-count`·`board/queue-count-query`, `queue.e2e.ts`의 칩·배지 e2e.
</objective>
