## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 어느 사이트에서든(iframe 본문 포함) 원하는 요소를 마우스를 대충 가져가거나 숫자 키 하나로 누르고, 방해되면 즉시 끌 수 있기를, **so that** 떨림으로 인한 잘못 누름과 위험한 버튼 오조작 없이 평소 사이트를 빠르게 쓸 수 있다.

<objective>
Gap closure 안전장치 둘과 phase 마감 게이트를 다룬다.
(1) 검증기가 코드를 읽다가 찾은 결함: 자식 프레임에서 이미 차오르던 머무르기가 맨 위 위험 확인 화면이 떠 있는 동안에도 계속 차올라, 확인 화면 뒤 일반 요소를 누를 수 있다. 재현을 먼저 하고 그 뒤에 고친다.
(2) IN-04(01-REVIEW): `site/query`가 실패하면 "이 사이트에서 끄기"가 fail-open된다. 실패해도 안전하고 이용자에게 보이게 고친다.
(3) 싼 게이트 → DOM 감사 재실행 → 전체 게이트 한 번 → 네트워크 API grep.

Purpose: SAFE-01·CLICK-04(위험 버튼은 머무르기로 눌리지 않음, D-18/D-19 확인 화면 보호), SAFE-04(방해되면 바로 끄기, D-20). 이 계획이 phase 금지사항 "확인 화면을 거치지 않은 누름 없음", "끈 사이트에서 조용히 다시 돌지 않음"을 맡는다.
Output: `dwell-frame.html`, dwell·site-toggle e2e 추가, `content.ts` 수정, `background.ts` e2e 훅, 전체 게이트 결과.
</objective>
