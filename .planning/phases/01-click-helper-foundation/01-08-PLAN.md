## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 어느 사이트에서든(iframe 본문 포함) 원하는 요소를 마우스를 대충 가져가거나 숫자 키 하나로 누르고, 방해되면 즉시 끌 수 있기를, **so that** 떨림으로 인한 잘못 누름과 위험한 버튼 오조작 없이 평소 사이트를 빠르게 쓸 수 있다.

<objective>
위험한 버튼을 알아보고 자석 커서에서 떼어 놓는다: 단어 목록으로 판별하고, 자석이 끌어당기지 않으며 커서가 정확히 위에 있을 때만 잡히고, 빨간 점선으로 보인다. 번호표로 고른 위험한 버튼의 확인 화면은 Plan 01-09 — 그 전까지 숫자로는 누르지 않는다.

Purpose: SAFE-01(D-18, D-30). 머무르기 클릭 예외는 머무르기가 생기는 Plan 01-10에서 확인한다. 표시 규칙(D-26).
Output: `danger.ts`+단위 시험, `magnet.ts` 위험 예외+단위 시험, 수집기 위험 표시, 위험 테두리, 연습 페이지 `danger.html`, e2e.
</objective>

## 가정 (spec-less edge probe)

- SAFE-01은 주 계획이 이 계획이고, 머무르기 예외 부분은 Plan 01-10에서 검증한다. edge probe `unclassified — review manually`. 가정한 경계:
  - 판별은 요소 이름(aria-label → 라벨 → 글자 → value → alt/title)에 단어가 들어 있는지, 공백 무시. "취소"가 들어간 무해한 버튼(예: "검색 조건 취소")도 위험으로 본다 — 보수적 방향(잘못 누름 방지 우선).
  - 커서가 정확히 위에 있을 때의 클릭·스페이스바는 이용자가 직접 겨눈 누름이라 확인을 묻지 않는다(설계 8장은 번호표·자동 순서 선택에만 확인을 요구).
  - 사이트별 목록 편집(SAFE-06)은 Phase 3.
