## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 어느 사이트에서든(iframe 본문 포함) 원하는 요소를 마우스를 대충 가져가거나 숫자 키 하나로 누르고, 방해되면 즉시 끌 수 있기를, **so that** 떨림으로 인한 잘못 누름과 위험한 버튼 오조작 없이 평소 사이트를 빠르게 쓸 수 있다.

(ROADMAP Phase 1 **Goal** 문장을 그대로 세 칸에 옮긴 것이다. 새 내용은 더하지 않았다.)

`src/core/settings-schema.ts`(D-23, D-25): `CURRENT_SCHEMA_VERSION = 1`. zod 스키마 세 개와 기본값:
- `SETTINGS_KEY = 'settings'`, `SettingsV1` = `{ schemaVersion: 1, data: { enabled: boolean, keymap: { press: 'Space', confirm: 'Enter', cancel: 'Escape', toggleHints: 'KeyF' }, tremorIntervalMs: number(기본 300), sameSpotPx: number(기본 16), captureMarginPx: number(기본 48), switchHysteresisPx: number(기본 24), dwellEnabled: boolean(기본 false), dwellMs: number(기본 800), dragTwoPress: boolean(기본 false), dangerWords: string[](기본 ['삭제','취소','반려','로그아웃','결재 취소']) } }` — 키 값은 `KeyboardEvent.code` 문자열. `dangerWords` 기본값은 정확히 이 다섯 단어다(D-18, 외부 검토 제안을 이용자가 거절한 단어는 더하지 않는다).
- `siteKey(origin) = 'site:' + origin`, `SiteEntryV1` = `{ schemaVersion: 1, data: { disabled: boolean, pins: Array<{ number: 1..9, fingerprint: Fingerprint }> } }`(pins는 Plan 01-05가 읽는다. `Fingerprint`는 `{ id?, name?, labelText?, buttonText?, aria?, domPath: string, framePath: string[] }`).
- `pressesKey(origin) = 'presses:' + origin`(storage.local), `PressesV1` = `{ schemaVersion: 1, data: { counts: Array<{ fingerprint: Fingerprint, count: number }> } }`.
- `defaultSettings()`는 `SettingsV1`을 통과하는 기본값을 돌려준다. 초깃값들은 Phase 2 이용자 시험에서 맞출 설정값이다(CONTEXT "Claude's Discretion").
