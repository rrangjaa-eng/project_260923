## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 어느 사이트에서든(iframe 본문 포함) 원하는 요소를 마우스를 대충 가져가거나 숫자 키 하나로 누르고, 방해되면 즉시 끌 수 있기를, **so that** 떨림으로 인한 잘못 누름과 위험한 버튼 오조작 없이 평소 사이트를 빠르게 쓸 수 있다.

<objective>
번호표로 고른 위험한 버튼에 확인 화면을 붙인다: 빨간 테두리 카드가 "정말 누를까요? Enter = 예"를 묻고, 뜬 뒤 1초는 모든 입력을 무시하며, 확인은 진짜 Enter 또는 스페이스바 1초 누르기로만, 취소는 Esc. iframe 안 위험 버튼도 같은 확인을 거친다.

Purpose: SAFE-02(D-18), SAFE-03(D-19), 가짜 입력으로 확인되지 않음(D-09), 확인 카드 규칙(D-26). 이 계획이 phase 금지사항 "확인 없이 위험 버튼 누르기 금지"를 맡는다.
Output: `confirm-guard.ts`(순수)+단위 시험, `confirm-dialog.ts`, 위험 번호표 표시, 파이프라인 확인 모드, 프레임 사이 확인 키 전달, e2e.
</objective>
