## Phase Goal

**As a** 손 떨림이 있는 이용자, **I want to** 어느 사이트에서든(iframe 본문 포함) 원하는 요소를 마우스를 대충 가져가거나 숫자 키 하나로 누르고, 방해되면 즉시 끌 수 있기를, **so that** 떨림으로 인한 잘못 누름과 위험한 버튼 오조작 없이 평소 사이트를 빠르게 쓸 수 있다.

<objective>
저장 형식이 바뀌다 실패해도 원래 데이터를 지키고 알린다. 동기화 항목 크기 한도를 지킨다. 업데이트·재시작 뒤 옛 도우미가 스스로 물러나고 새 도우미가 한 번만 들어간다.

Purpose: STOR-02(D-25), 항목 8KB(D-24), 옛 도우미 정리·새로 넣기(D-22), 알림 표시(SYSTEM.md 토스트, D-26), 단위 시험(D-30).
Output: `migrate()`·`syncItemBytes()`+단위 시험, writer의 보존·알림 기록, 메뉴 경고 카드, 토스트, 옛 도우미 자기 정리, `onInstalled` 새로 넣기, e2e.
</objective>

## 가정 (spec-less edge probe)

- STOR-02: edge probe `unclassified — review manually`(Plan 01-01 항목 포함). 가정한 경계:
  - Phase 1의 형식은 v1이 처음이라 실제 옛 형식이 없다. 변환 차례 적용은 주입한 변환 목록으로 단위 시험하고, 실제 실패 경로는 "모르는 새 버전"과 "잘못된 값"으로 e2e 시험한다.
  - 변환에 실패한 키는 이용자가 메뉴에서 바꿔도 저장하지 않는다(원본 보존 우선). 복구 방법(파일 내보내기 등)은 STOR-04(Phase 3).
  - 알림은 페이지 토스트(한 번)와 메뉴 경고 카드 두 곳. 모드 표시에는 넣지 않는다.
  - SW가 쉬면(유휴 30초) 포트가 끊기므로 `chrome.runtime.id`가 살아 있으면 다시 연결한다(RESEARCH Pattern 6).
