# 손 떨림 브라우저 도우미 (이름 미정)

## What This Is

손 떨림과 불수의 운동이 있는 뇌병변 장애 이용자 **한 사람**이 여러 윈도우 PC의 크롬·엣지·웨일에서 일반 웹서핑과 자동화를 빠르게 하도록 돕는 Manifest V3 확장 프로그램이다. 작은 버튼·이미지·입력칸을 마우스로 정확히 누르지 않아도 키 한두 번이나 마우스를 대충 가져가는 것만으로 누를 수 있게 하고, 선택적인 USB/외장 SSD용 C# 실행기가 canvas·주소창·탭·파일 창의 실제 입력을 맡는다. 회사 시스템 전용 업무 자동화는 이 범용 기반 다음 단계에서 구축한다. 헤드 마우스 같은 보조기기와 카메라 입력은 쓰지 않는다.

## Core Value

**어느 사이트에서든 원하는 요소를 키 한두 번 또는 마우스를 대충 가져가는 것만으로 누를 수 있다** — 평소 사이트를 쓸 때의 속도가 가장 중요하고, 다른 모든 기능이 실패해도 이것만은 동작해야 한다. 그리고 되돌릴 수 없는 제출은 항상 이용자 확인 뒤에만 일어난다.

### Active

- [ ] 요소 수집기: 모든 프레임에서 누를 수 있는 요소(버튼·링크·입력칸·클릭 이벤트가 걸린 이미지)를 찾아 목록으로 만들고 화면 변화 시 갱신한다
- [ ] 떨림 걸러내기: 설정 간격 안의 같은 키·같은 자리 재입력 무시, 자동 반복 끔, 의도치 않은 더블클릭 축소, 끌어서 놓기를 두 번 누르기로
- [ ] 자석 커서: 가장 가까운 요소를 잡아(히스테리시스) 클릭·스페이스바로 누른다. 빈 곳 클릭은 그대로, 위험한 버튼은 끌어당기지 않는다
- [ ] 번호표: 고정 번호 → 자주 누른 요소 → 마우스 근처 순으로 1~9 번호를 붙이고 숫자 키로 누른다
- [ ] 자동 순서 강조, 머무르기 클릭(위험한 버튼 제외)
- [ ] 도우미 끄기: 전체 또는 지금 사이트에서만, 명령판과 아이콘에서
- [ ] 입력 모드 표시: "입력 중 / 도우미" 상태를 크게 표시하고 입력칸·contenteditable에서는 키를 원래대로 둔다
- [ ] 키 스크롤, 명령판(0), 되돌리기(Esc로 뒤로, 입력 되돌리기)
- [ ] 입력 줄이기(최근 값·자주 쓰는 문구 카드, Alt+1~9), 양식 한 장 보기
- [ ] 컨디션 모드(좋은 날 / 힘든 날), 처음 설치할 때의 맞춤 설정
- [ ] 틀 자동화: 기록, 요소 찾기(여러 방식 점수), 실행(속도 3단계, 실행 잠금), 제출 전 확인, 알림 창 처리, 막힘과 단계 다시 기록
- [ ] 활동 기록(2주, 입력 값 제외, 내보내기 전 확인), 주간 진행 통계
- [ ] 작업판(탭 카드, 자주 가는 곳, 뒤에서 도는 틀, 확인 대기), 뒤에서 실행, 이미지·광고 차단, 반복 패턴 알림
- [ ] 화면 정리(AI, 키를 누를 때만): 요소 목록을 작은 Claude 모델에 보내 중요한 9개에 번호표를 붙인다. 답 검사, 한 달 한도, 키 없으면 이 기능만 꺼짐
- [ ] 민감한 칸·위험한 버튼 판별과 사이트별 이용자 설정, 확인 화면 보호(1초 입력 무시, Enter로만 확인)
- [ ] 저장과 동기화: sync/local/session 구분, 형식 버전과 안전한 변환, 설정·틀 파일 내보내기·가져오기
- [ ] 휴대형 손: USB/외장 SSD의 C# 단일 실행 파일을 실행 중에만 확장과 연결해 canvas 좌표·드래그·주소창·탭·파일 창을 조작하고 긴급 정지한다
- [ ] 휴대형 보호 저장소: USB를 설정 기준 원본으로 삼고 이용자가 항목별 일반/보호/민감을 정하며, 명시적으로 허용한 모든 값은 PIN으로 잠근 암호화 저장소에 보관한다

### Out of Scope

- 윈도우 프로그램 전체 자동화(엑셀·한글 등의 머무르기 클릭·번호표) — 휴대형 실행기의 첫 범위는 canvas·브라우저 UI·파일 창까지
- 엑셀·다른 사이트 정보를 입력칸으로 옮기기, 여러 건 한꺼번에 입력 — 다음 버전
- 안드로이드 접근성 도우미 앱, 아이폰 — 다음 버전(아이폰은 통신사 연결이 없어 그 뒤)
- AI 글 써 주기, AI 틀 복구 — 다음 버전. AI는 화면 정리 한 곳에만 쓴다
- 보안 키패드 대신 누르기, 자동입력 방지 문자 풀기 — 하지 않음(보안 우회)
- 화면을 거치지 않고 사이트에 요청 직접 보내기 — 하지 않음(사이트 입력 검사를 건너뜀)
- 서버 운영 — 하지 않음. 데이터는 이용자 USB/외장 SSD와 최소한의 브라우저 저장소에만 둔다
- 쇼핑·결제 화면 자동화 — 이용자가 쇼핑을 하지 않고, 결제 화면은 만나면 멈춘다
- 위험한 버튼 판별 단어에 결재·상신 추가, 자석 커서 확인 추가 — 외부 검토에서 제안됐으나 이용자가 거절

## Context

- **이용자:** 한 사람. 손 떨림·불수의 운동, 손을 거의 못 쓰는 날도 있다. 가장 중요한 건 평소 사이트 속도, 그다음이 회사 웹 시스템 반복 입력 자동화
- **기준 설계:** `docs/superpowers/specs/2026-09-23-tremor-browser-helper-design.md` (브레인스토밍 합의, CEO 리뷰·외부 검토 반영). 디자인 리뷰와 엔지니어링 리뷰는 아직 PENDING
- **참고 제품:** Vimium식 링크 힌트(번호표), Automa식 기록기(틀), Steady Clicks식 클릭 필터(떨림 걸러내기). 이 셋을 한 이용자를 위해 제출 안전장치와 함께 묶은 제품은 없어서 처음부터 만든다
- **회사 시스템:** 본문이 iframe 안에 있는 경우가 많고, `alert`/`confirm`을 자주 띄운다. 실제 회사 시스템에서는 시험하지 않고 로컬 연습용 가짜 사이트에서만 시험한다
- **구현 전 확인할 점(설계 11장):** ① 확장이 발생시킨 클릭을 받지 않는 사이트 ② 회사 PC의 확장 설치 차단 정책 ③ 뒤쪽 탭 타이머 속도 제한 ④ 숫자·스페이스바를 쓰는 사이트 단축키와의 충돌
- **저장소:** 루트 `CLAUDE.md`는 이 프로젝트의 안정적인 제품·도구·품질 규칙만 두고, 진행 상황과 미결 결정은 `.planning/`과 결정문에 기록한다

## Constraints

- **Tech stack**: Manifest V3 확장, TypeScript strict, `any` 금지 — 저장소 규칙. 빌드 도구는 구현 계획에서 정한다
- **Package manager**: pnpm만 — 저장소 규칙
- **Compatibility**: 윈도우 PC의 크롬·엣지·웨일(모두 Chromium) — 이용자 환경
- **Distribution**: 크롬 웹스토어 비공개 링크, 지연 게시로 확인 후 공개. 되돌리기는 웹스토어 롤백 또는 더 높은 버전 번호로 재게시 — 자동 업데이트 구조 때문
- **Privacy**: 서버 없음. 보호 값은 이용자가 항목별 경고 뒤 허용한 것만 USB에 암호화 저장하고 AI에는 입력 값을 보내지 않는다. USB는 분실될 수 있으므로 기본값은 저장 금지·가림 — 이용자 데이터 보호
- **Safety**: 제출 성격의 단계는 항상 이용자 확인 뒤에만, 절대 재시도하지 않음. 확인 화면이 뜬 뒤 1초 입력 무시, 확인은 Enter(또는 스페이스바 1초) — 떨림으로 인한 되돌릴 수 없는 일 방지
- **Performance**: 요소 5,000개 페이지에서 커서 이동 후 강조가 50ms 안에 따라온다. 마우스 계산은 초당 60회 이하, MutationObserver 갱신은 모아서 — 속도가 핵심 가치
- **Storage**: USB/외장 SSD가 설정 기준 원본. 브라우저 저장소는 USB가 없을 때의 비민감 기본값과 실행 중 최소 복사본만 보관한다. 보호 값은 PIN으로 잠근 암호화 저장소에만 둔다
- **Security**: 모든 사이트 접근 권한 필요(설치 화면에 고지). AI 사용 키는 이 PC에만, 코드·커밋에 시크릿 금지
- **Testing**: 모든 기능은 로컬 연습 사이트에서 먼저 시험. 실제 회사 시스템에서는 시험하지 않음
