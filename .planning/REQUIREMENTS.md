# Requirements: 손 떨림 브라우저 도우미 (이름 미정)

**Defined:** 2026-09-23
**Core Value:** 어느 사이트에서든 원하는 요소를 키 한두 번 또는 마우스를 대충 가져가는 것만으로 누를 수 있다. 되돌릴 수 없는 제출은 항상 이용자 확인 뒤에만 일어난다.

기준: `docs/superpowers/specs/2026-09-23-tremor-browser-helper-design.md` (괄호 안 숫자는 설계 장 번호). "이용자"는 손 떨림이 있는 실제 이용자 한 사람이다.

## v1 Requirements

### 요소 수집 (ELEM)

- [ ] **ELEM-01**: 이용자가 보는 페이지에서 버튼·링크·입력칸·클릭 이벤트가 걸린 이미지가 도우미의 "누를 수 있는 요소"로 인식된다 (4)
- [ ] **ELEM-02**: iframe 안(중첩·다른 출처 포함)의 요소도 똑같이 인식되고, 번호표·강조가 맨 위 화면에 겹침·중복 번호 없이 표시된다 (4)
- [ ] **ELEM-03**: 화면 내용이 바뀌거나(늦게 나타나는 입력칸 등) 스크롤해도 인식된 요소 목록과 강조 위치가 따라온다 (4)
- [ ] **ELEM-04**: 요소 5,000개짜리 연습 페이지에서 커서를 옮긴 뒤 강조가 50ms 안에 따라온다 (4)

### 떨림 걸러내기 (FILT)

- [x] **FILT-01**: 같은 키·같은 자리 클릭이 설정한 간격 안에 다시 들어오면 한 번으로 처리된다 (5)
- [x] **FILT-02**: 키를 오래 눌러도 한 번만 입력된다(자동 반복 끔) (5)
- [x] **FILT-03**: 의도치 않게 들어온 더블클릭이 한 번 클릭으로 줄어든다 (5)
- [ ] **FILT-04**: 이용자가 버튼을 계속 누르지 않고 "끌기 시작 → 놓을 곳 누르기" 두 번 누르기로 끌어서 놓기를 할 수 있다 (5)

### 클릭 도우미 (CLICK)

- [ ] **CLICK-01**: 마우스 커서에 가장 가까운 요소가 요소 크기보다 넓은 범위에서 잡혀 굵은 테두리로 크게 강조되고, 커서가 떨려도 다른 요소로 충분히 옮겨 가기 전에는 바뀌지 않는다 (6.1)
- [ ] **CLICK-02**: 요소가 잡힌 상태에서 클릭하거나 스페이스바를 누르면 커서 실제 위치와 상관없이 잡힌 요소가 눌리고, 잡힌 요소가 없을 때의 클릭은 원래대로 동작한다 (6.1)
- [ ] **CLICK-03**: 이용자가 단축키로 번호표를 켜면 고정 번호 → 자주 누른 요소 → 마우스 근처 순으로 1~9 번호가 붙고, 숫자 키로 그 요소를 누를 수 있다 (6.2)
- [ ] **CLICK-04**: 머무르기 클릭을 켜면 잡힌 요소 위에 커서가 설정 시간 머물 때 원이 차오르는 표시 뒤 눌리고, 그 전에 커서를 치우면 취소되며, 커서가 떠났다 돌아오기 전에는 다시 누르지 않는다 (6.4)
- [ ] **CLICK-05**: 자동 순서 강조를 켜면 번호표가 붙은 요소가 조절 가능한 간격으로 하나씩 강조되고 아무 키(기본 스페이스바)로 선택된다 (6.3)

### 키와 입력 모드 (KEY)

- [x] **KEY-01**: 커서가 입력칸이나 글쓰기 편집기(contenteditable) 안에 있으면 숫자·스페이스바가 원래대로 글자를 입력하고, Esc로 빠져나오면 도우미 키로 돌아가며, 지금 "입력 중 / 도우미"인지 화면 구석에 크게 표시된다 (5)
- [ ] **KEY-02**: 숫자·스페이스바를 자체 단축키로 쓰는 사이트에서도 도우미 모드일 때는 도우미 키가 먼저 동작한다 (11-④)

### 안전장치 (SAFE)

- [ ] **SAFE-01**: 위험한 버튼(삭제·취소·반려·로그아웃·결재 취소 등)은 자석 커서가 끌어당기지 않아 커서가 정확히 위에 있을 때만 잡히고, 머무르기 클릭이 동작하지 않는다 (8)
- [ ] **SAFE-02**: 번호표나 자동 순서 강조로 위험한 버튼을 고르면 빨간 테두리와 함께 "정말 누를까요? Enter = 예"를 한 번 더 묻는다 (8)
- [ ] **SAFE-03**: 확인 화면이 뜬 뒤 1초 동안 모든 입력이 무시되고, 확인은 Enter(또는 스페이스바 1초 누르기)로만, 취소는 Esc로 된다 (5)
- [ ] **SAFE-04**: 이용자가 확장 아이콘에서(명령판이 생기면 명령판에서도) 도우미 전체 또는 지금 사이트에서만 도우미를 끄고 켤 수 있다 (8)
- [ ] **SAFE-05**: 확장이 동작하지 않는 페이지(브라우저 설정, 웹스토어 등)에서는 확장 아이콘에 "도울 수 없음"이 표시된다 (9)
- [ ] **SAFE-06**: 이용자가 위험한 버튼 단어 목록을 사이트마다 고칠 수 있다 (8)

### 저장과 동기화 (STOR)

- [ ] **STOR-01**: 조작 설정·사이트별 끄기·고정 번호 같은 설정이 같은 브라우저 계정으로 로그인한 다른 PC에 그대로 적용된다 (7)
- [ ] **STOR-02**: 저장된 데이터가 새 형식으로 바뀌다 실패하면 원래 데이터가 그대로 남고 이용자에게 알림이 뜬다 (7)
- [ ] **STOR-03**: 동기화 용량을 넘기 전에 알림이 뜨고 자주 쓰는 문구부터 파일 내보내기가 안내된다 (7)
- [ ] **STOR-04**: 이용자가 설정을 파일로 내보내고 다른 브라우저(크롬↔엣지↔웨일)에서 가져올 수 있다 (7)

### 이동과 명령판 (NAV)

- [ ] **NAV-01**: ↑↓로 한 화면의 80%씩 부드럽게 스크롤되고, 스크롤 영역이 여러 개면 자석 커서가 있는 영역이 움직인다 (6.5)
- [ ] **NAV-02**: 0을 누르면 명령판이 뒤로·앞으로·새로고침·탭 닫기·새 탭 등 명령을 큰 번호 카드로 보여 주고, 첫 화면에 키 안내 카드(알림 창 Enter=확인·Esc=취소 포함)가 있다 (6.5)
- [ ] **NAV-03**: 번호·자석 커서로 링크를 눌러 페이지가 바뀐 직후 Esc를 누르면 이전 페이지로 돌아간다 (6.5)
- [ ] **NAV-04**: 입력칸에 방금 넣은 값을 명령판의 "입력 되돌리기"로 되돌릴 수 있다 (6.5)
- [ ] **NAV-05**: 이용자가 명령판에서 이 사이트의 특정 요소에 번호를 고정하고, 번호가 9개를 넘으면 "다음 번호"로 넘길 수 있다 (6.2)
- [ ] **NAV-06**: 더블클릭이 필요한 곳에서 명령판의 "더블클릭"으로 더블클릭할 수 있다 (5)

### 입력 돕기 (INPT)

- [ ] **INPT-01**: 입력칸을 누르면 그 칸(사이트 + 칸 이름)의 최근 입력 값과 자주 쓰는 문구가 번호 카드로 뜨고 Alt+1~9로 고를 수 있다 (6.6)
- [ ] **INPT-02**: 이용자가 자주 쓰는 문구를 저장하고 고칠 수 있다 (6.6)
- [ ] **INPT-03**: 명령판에서 "양식 한 장 보기"를 켜면 페이지의 입력칸이 큰 제목이 붙은 큰 칸으로 한 줄씩 모이고 선택 목록은 번호 카드가 되며, 입력한 값이 원래 칸에 사이트가 알아채게 채워지고, 제출 버튼은 없이 "원래 화면으로"로 닫힌다 (6.7)

### 민감한 칸 (PRIV)

- [ ] **PRIV-01**: 비밀번호 칸과 이름·라벨에 비밀번호·PW·인증번호·OTP·보안카드가 들어간 칸, 그리고 주민·계좌·카드 칸 중 값이 그 번호 모양인 칸의 값은 최근 입력·틀·활동 기록·AI 전송 어디에도 남지 않는다 (8)
- [ ] **PRIV-02**: 이용자가 사이트마다 칸을 "민감함 / 민감하지 않음"으로 정할 수 있고, 풀 때 한 번 더 확인하며, 비밀번호 칸을 풀 때는 "이 칸의 값이 이 PC와 틀 파일에 암호화 없이 저장됩니다" 경고를 본다 (8)
- [ ] **PRIV-03**: 이용자가 민감칸 판별 단어 목록을 더하고 뺄 수 있다 (8)

### 컨디션과 맞춤 (PERS)

- [ ] **PERS-01**: 이용자가 명령판에서 "좋은 날 / 힘든 날" 설정 묶음(조작 방식, 떨림 간격, 머무르기 시간, 강조 속도, 번호표·테두리 크기)을 한 번에 바꿀 수 있다 (6.11)
- [ ] **PERS-02**: 처음 설치할 때 큰 버튼을 차례로 누르는 맞춤 설정으로 떨림 간격과 편한 머무르기 시간이 재어져 두 컨디션 모드의 기본값이 정해지고, 나중에 명령판에서 다시 할 수 있다 (6.12)
- [ ] **PERS-03**: 이용자가 도우미 키 배치를 바꿀 수 있다 (5)

### 틀 자동화 (TMPL)

- [ ] **TMPL-01**: 이용자가 명령판에서 "틀 기록"을 켜고 평소처럼 한 번 입력하면, 누른 요소와 입력 값이 단계 목록으로 저장되고 끝나면 "틀 저장" 화면이 뜬다 (6.8)
- [ ] **TMPL-02**: 틀 저장 화면에서 날짜·금액·전화번호 같은 값이 "바뀌는 값" 후보로 표시되고, 이용자가 칸마다 번호로 "매번 바뀜 / 항상 같음"을 확정하고 틀 이름을 고른다 (6.8)
- [ ] **TMPL-03**: 마지막으로 누른 제출 성격의 버튼(저장·상신·등록·제출 등)이 제출 단계로 표시되고 이용자가 바꿀 수 있다 (6.8)
- [ ] **TMPL-04**: 틀을 실행하면 저장된 시작 페이지로 메뉴를 거치지 않고 곧장 이동한다 (6.8)
- [ ] **TMPL-05**: 실행 때 각 단계의 요소를 여러 기억 방식(id, name, 라벨·버튼 글자, aria, 위치 경로, 프레임 경로)으로 찾고, 확실한 요소가 없으면 누르지 않고 멈춘다 (6.8)
- [ ] **TMPL-06**: 이용자가 0 → 틀 실행 → 틀 번호로 틀을 고르면, 바뀌는 값마다 최근 값·오늘 날짜 같은 후보가 번호 카드로 뜨고 직접 입력도 할 수 있으며, 값을 다 받으면 단계가 실행된다 (6.8)
- [ ] **TMPL-07**: 이미 도는 틀을 다시 고르면 두 번째는 시작되지 않고 진행 중인 틀로 안내된다 (6.8)
- [ ] **TMPL-08**: 실행 속도를 천천히(단계마다 멈추고 강조) / 보통 / 최대(요소가 나타나는 즉시, 같은 화면 입력칸은 한 번에)로 정할 수 있고, 틀마다 기본값을 두며, 실행 중 ←→로 바꾸고 Esc로 멈춘다 (6.8)
- [ ] **TMPL-09**: 제출 단계 직전에 항상 멈춰 입력한 값을 큰 글씨로 요약해 보여 주고, Enter(또는 스페이스바 1초)로 제출, Esc로 취소한다 (6.8)
- [ ] **TMPL-10**: 제출 뒤 결과가 분명하지 않으면(성공 메시지·페이지 이동 없음) 다시 제출하지 않고 "확인 필요"로 표시된다 (6.8)
- [ ] **TMPL-11**: 틀 실행 중 확인한 제출 직후 처음 뜬 확인 창 하나에만 "확인"으로 답하고, 그 뒤의 예상하지 못한 확인 창은 "취소"로 답하고 멈춘 뒤 창의 글을 큰 글씨로 보여 주며, 단순 안내 창은 활동 기록에 남기고 닫는다. 틀 밖에서는 알림 창을 가로채지 않는다 (6.8)
- [ ] **TMPL-12**: 요소를 못 찾거나 화면이 예상과 다르면 그 자리에서 멈추고 알리며, 이용자가 "이 단계만 다시 기록"으로 그 단계를 직접 한 번 하고 확인한 뒤에만 틀에 반영된다 (6.8)
- [ ] **TMPL-13**: 틀 실행 중 확장 백그라운드가 잠들었다 깨어나도 저장된 단계에서 이어 가고, 제출 단계 도중이었다면 제출 여부가 불분명할 때 다시 누르지 않고 "확인 필요"로 둔다 (4)
- [ ] **TMPL-14**: 민감한 칸이 들어 있는 틀은 실행 때마다 그 칸에서 멈춰 이용자가 직접 입력하게 한다 (8)
- [ ] **TMPL-15**: 보안 키패드·자동입력 방지 문자·결제 화면을 만나면 자동으로 누르지 않고 멈춘다 (8)
- [ ] **TMPL-16**: 이용자가 틀을 파일로 내보내고 가져올 수 있고, 내보낼 때 "이 파일에는 틀에 저장된 고정 값이 들어 있습니다" 알림을 먼저 본다 (7)

### 활동 기록 (LOG)

- [ ] **LOG-01**: 최근 2주 동안의 동작(누른 것, 틀 진행, 알림 창 내용, 막힘·확인 필요)이 입력한 값 없이 이 PC에만 기록된다 (6.13)
- [ ] **LOG-02**: 이용자가 명령판에서 "기록 내보내기"를 누르면 내보낼 내용을 먼저 보고 확인한 뒤 파일로 저장된다 (6.13)
- [ ] **LOG-03**: 되돌리기 횟수와 틀 한 번에 누른 횟수 같은 주간 진행 통계를 볼 수 있다 (6.13)

### 작업판 (BORD)

- [ ] **BORD-01**: 이용자가 명령판이나 단축키로 작업판을 열어 열린 탭을 큰 번호 카드로 보고 번호로 이동하거나 닫을 수 있다 (6.9)
- [ ] **BORD-02**: 이용자가 자주 가는 사이트를 고정하고 작업판에서 번호로 이동할 수 있다 (6.9)
- [ ] **BORD-03**: 작업판에서 뒤에서 도는 틀의 진행 상황을 볼 수 있다 (6.9)
- [ ] **BORD-04**: 작업판의 확인 대기 목록에서 항목을 번호로 불러와 처리(값 고르기, 제출 확인)할 수 있다 (6.9)

### 뒤에서 실행 (BG)

- [ ] **BG-01**: 이용자가 틀을 뒤쪽 탭에서 돌리는 동안 다른 탭에서 계속 일할 수 있고, 이용자가 해야 할 일이 생기면 확인 대기에 쌓인다 (6.8)
- [ ] **BG-02**: 뒤에서 도는 탭이 닫히거나 로그아웃되면 그 틀이 멈추고 작업판에 이유가 표시된다 (9)
- [ ] **BG-03**: 틀마다 이미지·광고 차단을 켜면 그 틀을 실행하는 탭에서만 이미지·광고 요청이 막힌다 (6.8)

### 반복 패턴 알림 (PATN)

- [ ] **PATN-01**: 같은 사이트의 같은 입력칸 묶음에 틀 없이 3번 이상 입력하면 "이걸 틀로 저장할까요?"를 한 번 묻고, 거절하면 그 패턴은 다시 묻지 않는다 (6.8)

### 화면 정리 AI (AI)

- [ ] **AI-01**: 이용자가 명령판에서 "화면 정리"를 누르면 이 화면에서 중요한 요소 9개에 1~9 번호표가 붙는다 (6.10)
- [ ] **AI-02**: AI로 보내는 것은 요소 종류·보이는 글자·대략의 위치뿐이고, 입력칸 값은 보내지 않으며 이메일·전화번호·긴 숫자 같은 개인정보 모양은 가려진다 (6.10)
- [ ] **AI-03**: 같은 사이트·같은 페이지 주소에서는 저장된 결과를 다시 쓰고 AI를 다시 부르지 않는다 (6.10)
- [ ] **AI-04**: 이용자가 정한 한 달 사용 한도를 넘으면 AI를 부르지 않고 알린다 (6.10)
- [ ] **AI-05**: AI 사용 키가 없으면 화면 정리만 꺼지고 나머지는 모두 동작하며, 키는 이 PC에만 저장되고 동기화되지 않는다 (6.10, 7)
- [ ] **AI-06**: AI 답이 보낸 목록에 없는 요소를 고르거나 호출이 실패하면 그 답을 버리고 자주 누른 순서 번호표로 대신하며, AI 결과로 요소가 직접 눌리는 일은 없다 (6.10)

### 이용자 시험 (TEST)

- [ ] **TEST-01**: 실제 이용자가 연습 사이트에서 정해진 과제(작은 버튼 10개 누르기, 양식 하나 채우기)를 확장 없이 할 때와 있을 때의 시간과 잘못 누른 횟수가 기록된다 (10)
- [ ] **TEST-02**: 이용자 시험 결과로 떨림 간격·잡는 범위·머무르기 시간 기본값이 조정되어 확장에 반영된다 (10, 10-1)
- [ ] **TEST-03**: 이용자 시험 결과에 따라 이후 만드는 순서를 유지할지 조정할지가 결정되어 기록된다 (10, 10-1)

### 배포 (DIST)

- [ ] **DIST-01**: 이용자가 크롬 웹스토어 비공개 링크로 자기 PC에 확장을 설치할 수 있고, 설치 화면에서 모든 사이트 접근 권한이 필요한 이유를 안내받는다 (7, 8)
- [ ] **DIST-02**: 새 버전은 연습 사이트 시험을 모두 통과한 뒤 지연 게시로 확인 후 공개되고, 문제가 생기면 웹스토어 롤백(안 되면 더 높은 버전 번호로 재게시)으로 되돌릴 수 있다 (8)

## Out of Scope

| Feature | Reason |
|---------|--------|
| 보안 키패드 대신 누르기, 자동입력 방지 문자 풀기 | 보안 우회. 만나면 멈춘다 (3, 8) |
| 화면을 거치지 않고 사이트에 요청 직접 보내기 | 사이트의 입력 검사를 건너뛰게 된다 (3) |
| 민감한 칸의 값 저장 | 개인정보. 이용자가 직접 푼 칸만 예외 (3, 8) |
| 서버 운영 | 모든 데이터는 이용자 PC와 브라우저 계정 동기화에만 (3) |
| 제출 자동 재시도 | 중복 상신·등록 위험. "확인 필요"로 둔다 (8) |
| AI가 요소를 직접 누르기 | AI는 번호만 붙인다 (6.10) |
| 위험한 버튼 단어에 결재·상신 추가, 자석 커서 확인 추가 | 외부 검토 제안을 이용자가 거절 (GSTACK REVIEW REPORT) |
| 쇼핑·결제 자동화 | 이용자가 쇼핑을 하지 않고, 결제 화면은 멈춘다 (1, 8) |
| 실제 회사 시스템에서의 시험 | 모든 시험은 로컬 연습 사이트에서만 (10) |
| 카메라·헤드 마우스 입력 | 이용자가 쓰지 않는다 (1) |
